# 治理、资料权威与统一术语

状态：本实施包现行基线。适用范围：ANovelOS V2；不自动宣称运行能力已验证。

## 1. 唯一实施入口

用户明确的路线、范围与后续修订优先。本包统一已有资料中的实施决定；现行正文描述语义，`machine/` 定义任务身份、阶段、门禁、决策和证据编码；二者必须一致。发现冲突应使校验失败，不能由开发者自行选择更宽松解释。

已登记且生效的后续 ADR 可以显式修订本包，必须同步源文件、影响任务、视图、校验与变更原因。机器文件和正文没有“互相覆盖以掩盖冲突”的权限。

## 3. 稳定术语

- **Canon**：经唯一提交服务接受的项目/分支叙事记录及其投影。摘要、缓存、模型记忆、计划、草稿均不拥有同等权威。
- **NarrativeDelta**：从候选正文提出的结构化变化；不是已确认事实。
- **ChangeSet**：经过类型化、作用域和前置条件校验的提交提议。
- **CommitPermit**：受控签发、绑定具体候选及必跑检查的执行许可；不因一个对象写 ALLOW 就有效。
- **Contract**：当前任务冻结的要求，包含硬要求与可调创作目标。它不能改写历史 Canon。
- **ContextArtifact**：为特定角色编译的输入。没有自动升级其来源权威的能力。
- **EvidenceRecord**：检查或评估证据；**ReferenceEvidencePack**：外部参考分析结果；两者名称、来源和权限分离。
- **Task status**：任务交付状态；**Gate status**：能力验收状态；**document validation**：资料一致性结果。三者不得互相代替。

## 4. 证据编码唯一版本：EVIDENCE-1

| 编码 | 来源含义 | 权限说明 |
|---|---|---|
| E0 | 确定性检查 | 仅在声明的约束和有效输入范围内可形成硬门禁证据 |
| E1 | 结构化抽取提议 | JSON 合法不等于叙事事实成立，不单独放行 |
| E2 | 模型评价，包括模拟读者 | 诊断/排序；不能冒充人工 Gold 或真实市场 |
| E3 | 真人 Gold、人工盲评 | 校准及人工决策证据，具体操作仍需权限校验 |
| E4 | 真实读者行为、真实市场观测 | 产品结果证据，不能改写 Canon 或世界规则 |

每条证据同时记录 `source_kind`、`verification_status`、`authority_scope`、`calibration_ref` 和来源版本。编码不构成通用可靠性排序。模型提议经确定性规则校验时，保留原 E1/E2 来源并新增 E0 检查记录，不将整个提议改标 E0。

旧 E 编码语义不明的数据不能无损猜测迁移；先保留原值/原定义，标记待判定。运行状态 UNKNOWN 与叙事未知值也必须分开建模。

## 5. 冻结与变更

稳定项：P0—P14 路线、双 Anchor、单 Canon 写入边界、Draft/Plan/Canon 分离、任务关闭证据、重大事故冻结功能。

按任务细化项：具体数据模型、字节规范、预算数值、迁移细节、真实模型选择。每项有最晚决策点；不要求所有未来 ADR 先完成。

发生 Canon 损坏、真实密钥泄露、重复提交、跨项目泄漏、硬门禁绕过或第二 Canon 写路径：暂停新功能，记录根因、修复、回归与验证后恢复。不得仅用改文档或修改阈值宣称恢复。

## 6. 外部经验的证据与采纳

[外部经验登记](machine/external-practice-register.yaml)独立于历史快照登记。其公开网页/仓库说明和 Issue 是设计输入，没有运行授权；Issue 只代表公开报告，未独立复现不得写成已证实的上游故障。Star、功能数量、作者自述和模型评分均不是本项目效果证据。

每项采纳绑定来源、已覆盖部分、具体改造、现行规范、任务和计划验收场景。`PLANNED` 只表示纳入实施要求；`VERIFIED` 必须有本地验收引用及关联任务/场景的验证证据。`DEFERRED` 不自动生成早期任务，也不因到达候选阶段而自动获得实施授权。

当前网络来源均为查阅日期对应的可变页面，未锁定上游 commit，未完成源码审计或部署验证。后续实际复用上游代码/提示词时，先记录不可变版本、具体路径、许可处理及适配差异；独立实现抽象机制则记录设计理由和本地验证，不强制克隆所有参考项目。任务关闭记录应说明采用方式，不能把“看过 README”写成“审计通过”。

## 7. 执行治理证据与历史来源追踪

v1.2 的 `plan_execution_evidence` 是任务/CI/决策的执行见证格式，不替代本节 E0–E4 叙事/评价证据体系。最低 CI、里程碑和阶段义务见 [governance-baseline.yaml](machine/governance-baseline.yaml)，批准摘要由验证器核对；生成视图不能重建最低义务。双向 ADR/finding 关联和 readiness/entry gate 都是实际检查。

[基础参考索引](machine/foundational-reference-register.yaml)只把历史研究归属接入现行任务，统一标 HISTORICAL_UNVERIFIED。它不声称本轮核实过论文、产品页面、性能数字或来源名称，不赋予历史报告执行权威，也不引入对应基础设施依赖。
