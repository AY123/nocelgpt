# 同类项目经验采纳与规划修订说明

日期：2026-09-20。对应资料版本：1.1.0。性质：现有实施计划的定向细化，不是新的总体架构。具体约束已合入 00、02—06、09、10 及 P0 执行方案；本说明用于解释原因与取舍。

## 1. 审核判断

需要吸收，但大部分价值应体现为更具体的接口边界、失败样本和验收要求。现有计划已有单 Canon 路径、草稿/计划分离、上下文预算、分层规划、Q0—Q3、有限修复及检查点恢复；无需因为外部项目拥有相似功能而再次新增同职责模块。

最明显的增量是：显式题材与可选套路分离、正文实际落点参与跨章接续、人物意图与知识被合约消费、不同入口共用执行服务、人工改稿后的证据失效，以及机制收益的对照验证。这些改进服务于稳定创作中文网文；没有一项能单独证明爆款能力。

本次保留 P0—P14、两个 Anchor、60 个任务的 ID/名称/阶段/依赖和原关键链。21 个现有任务补充 25 条验收场景，场景总数从 182 变为 207。所有任务仍 OPEN，所有业务测试仍 PLANNED，阶段和里程碑未被关闭。

## 4. 三个需要避免的误用

**把角色意图做成硬性剧情公式。** 目标、选择、代价用于规划和诊断，不强制每章升级、反转或改变外部状态。角色可以犯错，人物说服力不能由字段齐全自动认证。

**把记忆系统另建成真相源。** 索引、摘要、图谱和上下文清单均是可重建或可追溯的派生产物；发生冲突时不能覆盖 Canon。借鉴检索机制，不改变唯一提交边界。

**把修复评分或模拟读者当作发布资格。** 硬约束失败不能被总分抵消，模型读者属于 E2；真人盲评与市场分别保留 E3/E4。复杂管线可能更贵却不更好，应保留这个结果。

## 5. 暂缓与范围控制

- EXT-D01：完整作者工作台、自动开书和参考分析的产品体验，最早在 P10 重新考虑；最小 CLI 审阅和报告依旧属于当前任务。复杂编辑器须另有范围决定。
- EXT-D02：自动策略调优、大规模模拟读者循环，待 P11 实验/校准/晋级体系；真实市场反馈仍在 P13。
- EXT-R01：拒绝用 Agent 数量、题材模板数量、模型总分或仓库热度作为质量证明。这是本项目的判断，不是对来源项目的指控。

不因此新增图数据库、Agent Swarm、更多 GenrePack、趋势预测、整本反复重写或自动发表依赖。当前下一步仍是 P0；P0 只接入来源追踪与校验，业务机制到原有阶段再实施。

## 6. 实施时如何补足证据

独立实现机制：记录本地设计选择、适用约束和正反例结果。复用代码或提示词：额外登记上游不可变 revision、文件路径、许可处理、适配差异与回归结果。不要求所有任务先完成全面上游审计。

来源说明、代码复核、运行复现、本项目验收和阅读收益是不同事实。当前登记只完成第一层与任务分配；来源条目固定表达本次文档查阅，后续更高等级证据以单独记录引用，不覆盖原查阅事实。采纳项 VERIFIED 需关联任务/场景与本地证据，而不是修改一个标签。

## 7. 验证范围

资料验证检查冻结身份/阶段/依赖、来源与采纳引用、任务与断言一致、历史快照哈希、链接、生成视图及内容清单。验证器自测包括悬空来源、错误任务归属、未实现采纳被标为 VERIFIED，以及后期工作被提前接入等反例。

结果见[资料校验](../validation/plan-validation.json)及[验证器自测](../validation/validator-self-test.json)。这些结果不代表业务用例、数据库、CI、上游项目或双题材认证已经通过；阅读和商业收益仍待实施后验证。
