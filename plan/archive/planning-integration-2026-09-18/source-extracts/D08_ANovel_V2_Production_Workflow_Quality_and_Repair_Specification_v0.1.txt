原则：代码可以从零开始，认知、证据和失败经验不能从零开始。

1. 核心原则
Workflow 是唯一真实执行图；架构图不能只存在于文档/测试。
每个 Stage 必须声明 input/output schema、idempotency key、authority、retry、budget、checkpoint、side effect。
生产模式 Fail-Closed。
正文质量与事实合法性分层：硬事实错误不能被“平均分高”抵消。
Repair 优先局部 Patch，不默认整章重写。
2. 统一生产链
Canonical State + Genre/Story/Arc Goals        ↓Chapter Planner → Chapter Contract        ↓Scene Planner → Scene Contract        ↓Context Compiler (frozen artifact)        ↓Candidate Generator        ↓Q0 deterministic / Q1 canon / Q2 genre / Q3 transition        ↓Q4 narrative / Q5 character / Q6 commercial / Q7 originality        ↓Targeted Repair        ↓Final Validation        ↓Approval / Auto Permit        ↓Canon Commit + Receipt        ↓Next State
3. Context Compiler
Context 不应由 Writer 临时搜索和拼 Prompt。Compiler 根据 Contract、State 与 token budget 生成冻结的 ContextArtifact；生成、Reviewer 和修订都引用同一 artifact 或明确版本差异。

6. Patch-first Repair
Violation ↓ locate exact span / state mismatchRepairPlan {target_span, intent, protected_facts, allowed_delta} ↓Patch Candidate ↓Regression: Q0–Q7 ↓accept patch OR rollback
整章 rewrite 只在结构性失败时启用，并且必须重新跑全部 hard gates 和 delta extraction。

8. Resume 语义
Kill 任意 Stage 后重启，已成功且输入指纹一致的阶段不得重复计费。
Canon Commit 必须 exactly-once 或通过幂等键实现等价语义。
输入指纹变化时必须显式 invalidation downstream，而不是悄悄复用旧结果。
恢复后使用同一 accepted body hash；不能 Reviewer 验证 A、最终发布 B。
9. Human Gate
V2 的目标是高度自动化而非取消人类权威。发布、商业定价、重大 retcon、版权/相似性高风险、未校准 Genre 等默认保留 Human Gate；未来可按风险分级自动放行。
10. Observability
trace_id 串联 Genesis → Chapter → Model Call → Quality → Commit。
记录 token/cost/latency/retry/cache hit、validation failures、repair gain、manual intervention。
区分事实指标和代理指标，Dashboard 不得把“模拟分”展示成真实商业 KPI。
