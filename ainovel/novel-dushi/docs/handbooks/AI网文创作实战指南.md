# AI 网文创作实战指南（基于《我真没想重生啊》）

**用途**: 用于指导 AI 模型生成都市重生类网文  
**风格**: 接地气、口语化、节奏紧凑  
**日期**: 2026-09-09

---

## 🎯 核心原则（必须遵守）

### 1. 语言黄金三原则

```yaml
简洁原则:
  - 一句话能说清楚，不用两句
  - 能用5个字，不用10个字
  - 例子: "长得漂亮" > "她有着一双明亮的大眼睛..."

口语化原则:
  - 像人说话一样写
  - 例子: "咋办？" > "应该如何是好？"
  - 例子: "笑个屁" > "请不要笑了"

动作化原则:
  - 用动作代替描述
  - 例子: "一把牵起她的手" > "他伸出手握住了她的手"
  - 例子: "'嘿嘿'一笑" > "他显得很得意"
```

### 2. 描写长度限制

```yaml
人物外貌: 最多1行（12-15字）
  正确: "长得漂亮，身材修长匀称"
  错误: "她有着..."（超过20字）

场景描写: 最多2行（20-30字）
  正确: "建邺国际酒店金碧辉煌的包厢里"
  错误: 详细描述大厅、地毯、吊灯...

心理活动: 用"心说"、"想想"引入，不超过3行
  正确: "心说你再逼逼赖赖的，我真把她追到手"
  错误: 长篇内心独白
```

### 3. 对话比例要求

```yaml
每章构成:
  - 对话: 60%
  - 动作: 20%
  - 心理: 15%
  - 描写: 5%

对话要求:
  - 每句对话不超过30字
  - 必须推动情节
  - 必须有潜台词
  - 必须符合人物身份
```

## ✍️ 具体写作规则

### 规则1: 开场3段原则

**每章开场必须在3段内完成**:

```
第1段: 场景（1行）
例: "602宿舍里，陈汉升正躺在床上玩手机。"

第2段: 动作/对话（引入冲突）
例: "这时，王梓博突然推门进来：'老陈，出大事了！'"

第3段: 主角反应（推进情节）
例: "陈汉升'嗖'的一下坐起来：'咋了？'"
```

**禁止**:
- ❌ 长篇环境描写
- ❌ 回忆前情
- ❌ 大段心理活动

### 规则2: 对话写作规范

**基本格式**:
```
"对话内容。"（动作/表情/语气）
例: "你干嘛？"萧容鱼一把缩回手，瞪着他。
```

**禁用词汇**:
```yaml
禁止使用:
  - "道" → 用"说"
  - "缓缓" → 用"慢慢"或直接动作
  - "轻轻" → 能省就省
  - "柔声" → 不需要
  - "温柔地说" → 只用"说"
  - "笑着说" → 用"笑道"或"一笑"

推荐使用:
  - 说、问、答、道、骂、吼、笑
  - 一把、直接、马上、立即
  - 狗东西、笑个屁、咋办、干嘛
```

**对话长度**:
```
单句对话: 5-15字（最常见）
例: "你去哪儿？"
例: "不关你事。"

最长对话: 不超过30字
例: "你再逼逼赖赖的，我真把她追到手，看你到时哭去吧。"
```

### 规则3: 人物描写规范

**首次出场**（重要人物）:
```
格式: 名字 + 1行外貌 + 立即互动

例子:
"萧容鱼长得漂亮，身材修长匀称。
'你也来拿通知书？'陈汉升笑着走过去。"
```

**禁止**:
```
❌ "她的眉眼如画，肤若凝脂..."
❌ "一双明亮的大眼睛仿佛..."
❌ "长发如瀑布般..."
❌ 任何超过15字的外貌描写
```

**次要人物**:
```
格式: 名字 + 1个特征 + 立即互动

例子:
"高嘉良这小子也在建邺读书，他是一本的航空航天学院。"
（1个信息点足够）
```

### 规则4: 动作描写规范

**连续动作链**（最推荐）:
```
格式: 动作1 + 动作2 + 动作3（一气呵成）

例子:
"陈汉升一把牵起萧容鱼的手，假装看时间却在偷偷摸索，
萧容鱼一把缩回，怒气冲冲瞪着他。
陈汉升占到便宜，根本不留恋，直接唤起王梓博离开。"
```

**动词使用**:
```yaml
推荐:
  - 一把（牵起、抓住、拉过来）
  - 直接（走、说、离开）
  - 马上、立即、顿时
  - "嘿嘿"、"嘿"、"哼"

禁止:
  - 缓缓、慢慢、轻轻、柔柔
  - 小心翼翼、蹑手蹑脚
  - 任何超过3个字的副词
```

### 规则5: 心理活动规范

**格式**:
```
主角名 + 心说/想想/记得 + 口语化内容

例子:
"陈汉升心说你再逼逼赖赖的，我真把她追到手。"
"想想当年也是蛮可惜的，陈汉升直接忘记萧容鱼这个超级美女了。"
```

**长度限制**:
```
单次心理活动: 不超过3行
每章心理活动: 不超过5次
```

**禁止**:
```
❌ 长篇哲理思考
❌ "他想，人生就是..."
❌ "他突然明白了..."
❌ 任何说教性质的心理活动
```

## 🎬 场景写作模板

### 模板A: 主角遇女主

```yaml
步骤1: 场景（1行）
"陈汉升在教室门口，看到一个漂亮女生。"

步骤2: 外貌（1行）
"女生长得挺漂亮，身材也不错。"

步骤3: 搭讪（对话）
"'同学，你也是新生？'陈汉升走过去。"

步骤4: 互动（制造冲突）
"'嗯。'女生看了他一眼，没啥兴趣。"

步骤5: 主角行动（推进）
"陈汉升也不在意，笑了笑就走了。"

步骤6: 心理（暗示）
"心说这妞挺有意思，改天再说。"
```

### 模板B: 冲突场景

```yaml
步骤1: 引入对手
"这时，高嘉良走过来：'陈汉升，你离萧容鱼远点。'"

步骤2: 主角反应（痞气）
"陈汉升'嘿嘿'一笑：'凭什么？'"

步骤3: 对手升级
"'就凭她是我的...'高嘉良咬牙切齿。"

步骤4: 主角打断（不让冲突过度）
"'行了行了，懒得理你。'陈汉升摆摆手就走了。"

步骤5: 对手反应
"高嘉良气得脸都红了，却又没办法。"
```

### 模板C: 暧昧场景

```yaml
步骤1: 制造接触机会
"'现在几点？'陈汉升问。"

步骤2: 女主回应
"萧容鱼下意识抬起手腕：'5点25。'"

步骤3: 主角行动（占便宜）
"陈汉升一把牵起她的手，假装看时间。"

步骤4: 女主反应
"萧容鱼一把缩回，瞪着他。"

步骤5: 主角潇洒（欲擒故纵）
"陈汉升占到便宜，笑了笑就走了。"
```

## 📊 章节结构规范

### 标准章节结构（2500字）

```yaml
开场(200字, 8%):
  - 3段完成
  - 引入场景和冲突
  - 快节奏

中间(2000字, 80%):
  冲突1 (600字):
    - 对话为主
    - 制造矛盾
    - 快速解决
  
  过渡 (200字):
    - 场景转换
    - 或时间跳跃
  
  冲突2 (600字):
    - 升级矛盾
    - 或新冲突
  
  过渡 (200字)
  
  冲突3 (400字):
    - 小高潮

结尾(300字, 12%):
  - 留钩子
  - 引发期待
  - 过渡到下章
```

### 每章必备元素

```yaml
必须有:
  - 3-5个小冲突 ✓
  - 5-10组对话 ✓
  - 1-2个暧昧场景（感情线）✓
  - 1个章末钩子 ✓

必须避免:
  - 大段描写 ✗
  - 说教 ✗
  - 回忆前情 ✗
  - 平淡无冲突 ✗
```

## 💬 对话写作检查清单

### 每句对话必须满足以下之一:

```yaml
□ 推动情节
  例: "你去哪儿？" → 引出下个场景

□ 展现性格
  例: "笑个屁" → 展现主角痞气

□ 制造冲突
  例: "凭什么？" → 对抗

□ 传递信息
  例: "我是财经学院的" → 背景信息

□ 制造暧昧
  例: "以后多走动" → 暗示追求
```

### 对话禁止事项:

```yaml
✗ 寒暄式对话（无意义）
  "你好" "你好" "天气不错" "是啊"

✗ 说教式对话
  "你要记住，人生就是..."

✗ 信息堆砌
  "我叫XXX，今年XX岁，来自XXX，爱好是..."

✗ 文艺腔
  "今日天朗气清，惠风和畅"
```

## 🔥 冲突设计规范

### 冲突强度控制

```yaml
轻度冲突 (最常用):
  表现: 瞪眼、不理、走开
  例: 萧容鱼一把缩回，瞪着他
  解决: 主角走开，不纠缠

中度冲突:
  表现: 语言交锋、较劲
  例: "凭什么？" "就凭..."
  解决: 主角占上风，对方无奈

重度冲突 (少用):
  表现: 肢体冲突（推搡）
  例: 被人群挤开、推了一把
  解决: 点到为止，不打架
```

### 冲突"度"的掌握

**黄金原则**: 点到为止，留有余地

```yaml
正确示例:
  ✓ 高嘉良"睚眦欲裂" （内心气，但没动手）
  ✓ 萧容鱼"怒气冲冲瞪着" （生气，但没翻脸）
  ✓ 陈汉升"占到便宜就走" （得了便宜，不嘚瑟）

错误示例:
  ✗ 高嘉良冲上来要打陈汉升 （太激烈）
  ✗ 萧容鱼扇陈汉升耳光 （关系崩了）
  ✗ 陈汉升当众羞辱高嘉良 （没底线）
```

## 🎓 实战案例对照

### 案例1: 人物出场

**❌ 错误写法**:
```
萧容鱼走了过来，她有着一双明亮的大眼睛，
长长的睫毛在阳光下轻轻颤动，高挺的鼻梁下
是一张樱桃小嘴，瀑布般的长发随风飘扬...
（50字+，太长）
```

**✅ 正确写法**:
```
萧容鱼长得漂亮，身材修长匀称。
"你也来拿通知书？"陈汉升走过去。
（15字外貌+立即互动）
```

### 案例2: 冲突处理

**❌ 错误写法**:
```
高嘉良冲上来一把抓住陈汉升的衣领："你给我站住！"
陈汉升一拳打在高嘉良脸上："老子让你嘴贱！"
两人扭打在一起，旁边的人都来劝架...
（太激烈，后续没法写）
```

**✅ 正确写法**:
```
高嘉良看的睚眦欲裂，心里骂道："狗日的陈汉升！"
陈汉升占到便宜，笑了笑就走了。
（点到为止，还能继续互动）
```

### 案例3: 暧昧场景

**❌ 错误写法**:
```
"萧容鱼，我喜欢你，做我女朋友吧。"陈汉升深情地说。
萧容鱼脸红了："我...我..."
（太直接，暧昧没了）
```

**✅ 正确写法**:
```
"现在几点？"陈汉升问。
萧容鱼抬起手腕："5点25。"
陈汉升一把牵起她的手，假装看时间。
萧容鱼一把缩回，瞪着他。
陈汉升笑了笑就走了。
（不表白，更撩人）
```

## 💡 最后总结：必记5条

1. **语言要像说话** - "咋办？"不是"如何是好？"

2. **描写能省就省** - 1行外貌，2行场景，完

3. **冲突点到为止** - 瞪眼就够了，不要打架

4. **暧昧不要表白** - 行动说话，不要嘴上说

5. **对话推动情节** - 每句话都要有用
