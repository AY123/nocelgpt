## 🗣️ 第一部分：常用对话模板（可直接套用）

### A. 主角搭讪女主

**模板1 - 直接型**:
```
陈汉升: "同学，你也是XX吗？"
女主: "嗯。"（冷淡）
陈汉升: "加个微信呗/留个电话呗。"
女主: "不加。"或沉默
陈汉升: "那行吧。"（潇洒离开）
```

**模板2 - 借口型**:
```
陈汉升: "现在几点？"
女主: "X点X分。"（抬手看表）
陈汉升: （牵手）"挺漂亮的表。"
女主: （缩回）"你干嘛！"
陈汉升: （笑笑）走了
```

**模板3 - 邻居型**:
```
陈汉升: "你是XX大学的？"
女主: "嗯，你呢？"
陈汉升: "我是对门XX学院的，以后是邻居，可得多走动。"
女主: 沉默或冷淡回应
旁观者: "财院也就是个二本。"（挑衅）
陈汉升: "嘿嘿。"（不接话，直接走）
```

### B. 损友互怼

**模板1 - 调侃型**:
```
王梓博: "你咋XX了/你XX了？"
陈汉升: "XX罢了。"（敷衍）
王梓博: "你XX挺XX的。"（夸奖）
陈汉升: "熟能生巧。"或"习惯了。"
```

**模板2 - 关心型**:
```
王梓博: "老陈，出大事了！"
陈汉升: "咋了？"
王梓博: "XX说XX..."（传话）
陈汉升: "懒得理。"或"关我屁事。"
```

**模板3 - 吐槽型**:
```
陈汉升: "去帮我XX。"
王梓博: "又让我XX，你自己呢？"
陈汉升: "废话少说，去不去？"
王梓博: "去去去。"（嘴上抱怨，身体老实）
```

### C. 对手挑衅

**模板1 - 虚伪关心型**:
```
高嘉良: "XX，你不该这样，希望你能XX，我们都期待你XX。"
陈汉升: （盯着他看，不说话）
高嘉良: （浑身不自在）
陈汉升: "你他妈又是谁？"
高嘉良: "你太让人失望了。"（色厉内荏，找借口离开）
```

**模板2 - 炫耀型**:
```
高嘉良: "XX是XX（显摆），你XX也就是XX（贬低）。"
陈汉升: "嘿嘿。"或"哦。"（不接话）
高嘉良: （继续）"XX还XX..."
陈汉升: "懒得理你。"（直接走）
高嘉良: （气急败坏但没办法）
```

**模板3 - 拦路型**:
```
高嘉良: "陈汉升，你离XX远点。"
陈汉升: "凭什么？"
高嘉良: "就凭XX..."
陈汉升: "行了行了，懒得理你。"（不让他说完，直接走）
高嘉良: （气得脸红）
```

### D. 女主关心（傲娇）

**模板1 - 威胁式关心**:
```
女主: "你如果再XX，我就去告诉你妈/你爸。"
陈汉升: （配合）照做或"知道了。"
女主: （微笑，有点得意）
陈汉升: （内心）"这妞挺有意思。"
```

**模板2 - 送东西型**:
```
女主: "给你XX。"（递东西）
陈汉升: "谢谢，我自己有。"（拒绝）
女主: （倔强）还是放下，然后"哼"一声走了
陈汉升: （看着她背影，笑）
```

**模板3 - 教训型**:
```
女主: "你怎么可以XX！"（生气）
陈汉升: "XX罢了。"（不在意）
女主: "不行，你必须XX。"（坚持）
陈汉升: "行行行。"（敷衍但照做）
女主: （满意）
```

### E. 长辈对话

**模板1 - 奶奶/妈妈**:
```
奶奶: "这点钱你拿着，去XX买XX。"
陈汉升: "不要，我有钱。"
奶奶: "拿着拿着。"（塞钱）
陈汉升: "那我就拿XX（小额），意思意思。"
```

**模板2 - 父母唠叨**:
```
妈妈: "去了XX要XX，别XX，还要XX..."（一堆叮嘱）
陈汉升: "知道了知道了。"（不耐烦）
妈妈: "你这孩子..."
陈汉升: （内心）"唉，又来了。"
```

## ⚔️ 第二部分：冲突处理流程图

### 流程A：装逼打脸（最常用）

```
步骤1: 对手装逼
  ├─ 虚伪关心："希望你能..."
  ├─ 显摆优越："我XX，你XX..."
  └─ 贬低主角："XX也就XX..."

步骤2: 主角内心识破
  └─ "这话听起来XX，但是XX..."（1-2行内心独白）

步骤3: 用气场/行动压制
  ├─ 眼神："默不作声地盯着他"
  ├─ 动作："一把XX"
  └─ 不说话（让对手更慌）

步骤4: 对手气势败
  └─ "看得他浑身不自在"

步骤5: 补一句痞话
  └─ "你他妈又是谁？"/"懒得理你。"

步骤6: 对手找台阶
  └─ "太让人失望了。"（色厉内荏）

步骤7: 主角潇洒离开
  └─ 不纠缠，不羞辱到底

结果: 主角赢了，但没把对手逼死
```

### 流程B：暧昧推进（感情线）

```
步骤1: 制造接触机会
  ├─ 借口："现在几点？"
  ├─ 帮忙："我帮你XX。"
  └─ 偶遇："好巧啊。"

步骤2: 肢体接触
  ├─ 轻度："牵手看表"
  ├─ 中度："扶一下"
  └─ 重度："抱住"（慎用）

步骤3: 女主反应
  ├─ 缩回/推开（物理）
  └─ 瞪眼/脸红（情绪）

步骤4: 主角不纠缠
  └─ 占到便宜就走，不继续

步骤5: 女主后续
  ├─ 内心波动（想他）
  └─ 或找借口再接触

步骤6: 保持暧昧
  └─ 不表白，不确定关系

结果: 关系推进，但保持张力
```

### 流程C：损友互动（调节气氛）

```
步骤1: 王梓博提问/吐槽
  └─ "你咋XX了？"/"又XX？"

步骤2: 陈汉升敷衍
  └─ "XX罢了。"/"懒得说。"

步骤3: 王梓博继续
  ├─ 羡慕："挺XX的。"
  └─ 抱怨："你也不带我。"

步骤4: 陈汉升回应
  ├─ 调侃："笑个屁。"
  └─ 指使："去帮我XX。"

步骤5: 王梓博照做
  └─ 嘴上抱怨，身体老实

结果: 轻松幽默，推进情节
```

## 💬 第三部分：对话长度控制

### 快节奏场景（冲突、打脸）

**原则**: 每句5-15字

```
✓ "你是谁？"（3字）
✓ "关你屁事。"（4字）
✓ "懒得理你。"（4字）
✓ "你他妈又是谁？"（6字）
✓ "笑个屁。"（3字）
✓ "咋办？"（2字）

✗ "你这是在做什么呢，能不能解释一下？"（太长）
✗ "我觉得这样做是不太合适的。"（太正式）
```

### 慢节奏场景（暧昧、铺垫）

**原则**: 每句15-30字，偶尔可以更长

```
✓ "你要假装不认识，那我也没办法。"（13字）
✓ "以后咱们是邻居，可得多走动。"（13字）
✓ "我已经说的很清楚了，大学毕业前都不想谈朋友。"（22字）

但注意: 即使慢节奏，也不要超过30字一句
```

### 内心独白长度

**原则**: 2-3行，不超过50字

```
✓ "想想当年也是蛮可惜的，陈汉升上了大学就放飞自我，
   财院里美女资源又多，直接忘记萧容鱼这个超级美女了。"
   （38字，2行）

✗ "陈汉升想，人生就是这样，有时候..."（超过3行的都不要）
```

## 🎯 第四部分：冲突强度等级

### 一级冲突（最常用，80%）

**表现**:
- 瞪眼、不理、走开
- 内心不满（不说出来）
- 简短对抗（几句话）

**示例**:
```
女主: "你怎么可以XX！"
主角: "XX罢了。"
女主: （瞪眼）
主角: （不在意，走了）
```

**结果**: 矛盾存在但不激化

### 二级冲突（偶尔用，15%）

**表现**:
- 语言交锋（3-5个回合）
- 气势对抗
- 威胁（但不动手）

**示例**:
```
高嘉良: "你离她远点。"
陈汉升: "凭什么？"
高嘉良: "就凭..."
陈汉升: "懒得理你。"（打断他，走了）
高嘉良: （气急败坏）
```

**结果**: 主角占上风，对手无奈

### 三级冲突（少用，5%）

**表现**:
- 推搡（轻微肢体接触）
- 被逼到墙角
- 抓住衣领

**示例**:
```
对手: （抓住主角衣领）"你给我站住！"
主角: （一把推开）"放手。"
对手: "你..."
主角: "再碰我试试。"（眼神冷）
对手: （松手）
```

**结果**: 点到为止，不真打

### 四级冲突（禁用）

**禁止**:
- ✗ 真的打起来
- ✗ 见血
- ✗ 当众羞辱到底
- ✗ 撕破脸无法收场

**原因**: 
- 后续没法互动
- 不符合都市文风格
- 显得主角没底线

## 📋 第五部分：对话检查清单

### 每句对话必须满足（至少一项）:

```yaml
□ 推动情节
  例: "你去哪儿？" → 引出下个场景

□ 展现性格
  例: "笑个屁。" → 主角痞气

□ 制造冲突
  例: "凭什么？" → 对抗

□ 传递信息
  例: "我是财经学院的。" → 背景

□ 制造暧昧
  例: "以后多走动。" → 暗示

□ 调节气氛
  例: "你这狗东西。" → 损友幽默
```

### 对话禁用检查:

```yaml
✗ 寒暄式无效对话
  "你好" "你好" "天气不错" "是啊"

✗ 重复说明
  "我说了，我是XX，我来自XX，我的爱好是XX..."

✗ 说教式
  "你要记住，人生就是..."

✗ 文艺腔
  "今日天朗气清，惠风和畅"

✗ 超长句（超过30字）
  "我觉得这件事情应该这样做，首先我们要..."
```

## 🎭 第六部分：人物性格对话特征

### 主角（痞帅型）

**常用词**:
- "咋"、"啥"、"干嘛"
- "笑个屁"、"关你屁事"
- "懒得理"、"随便"
- "嘿嘿"、"呵"

**句式**:
- 简短直接："不去。"
- 反问："凭什么？"
- 敷衍："知道了。"
- 装逼："熟能生巧罢了。"

**禁用**:
- ✗ "我觉得这样不太好"
- ✗ "能不能请你..."
- ✗ "实在抱歉"
- ✗ 任何客套话

### 女主（高冷型）

**常用词**:
- "嗯"、"哦"、"随便"
- "你干嘛"、"不要"
- "哼"（不说话，只哼一声）

**句式**:
- 短句："不加。"
- 命令式："洗把脸。"
- 威胁式："我就告诉你妈。"
- 赌气式："那我也没办法。"

**禁用**:
- ✗ 主动表白
- ✗ 过于热情
- ✗ 长篇大论
- ✗ 解释太多

### 女主（温柔型）

**常用词**:
- "嗯嗯"、"好的"
- "那个..."、"我..."
- 声音小、不完整的句子

**句式**:
- 关心式："你吃饭了吗？"
- 担心式："会不会..."
- 温柔式："我给你XX。"

**禁用**:
- ✗ 强硬命令
- ✗ 大声说话
- ✗ 主动占便宜

### 损友（老实型）

**常用词**:
- "老陈"、"你咋"
- "这狗东西"（主角说他）
- "又XX"、"还XX"

**句式**:
- 唠叨式："你咋又XX了？"
- 羡慕式："挺XX的。"
- 抱怨式："你也不带我。"

**禁用**:
- ✗ 聪明点子（他是配角）
- ✗ 英明决断（他是跟班）

### 对手（舔狗型）

**常用词**:
- "容鱼"、"小鱼"（女主昵称）
- "希望你"、"我们都"
- 客套、正式的词

**句式**:
- 虚伪式："希望你能XX..."
- 显摆式："我XX，你XX..."
- 色厉内荏："太让人失望了。"

## 🔥 第七部分：高频对话组合

### 组合1：主角 + 女主（暧昧）

```
陈汉升: "XX？"（问题/借口）
女主: "嗯。"或简短回答

女主: "你干嘛！"（缩回）
陈汉升: （笑笑）走了
女主: （内心波动）
```

**使用时机**: 每章1-2次

### 组合2：主角 + 对手（打脸）

```

对手: "太让人失望了。"（找台阶）
陈汉升: 走了
```

**使用时机**: 每3-5章1次

### 组合3：主角 + 损友（调剂）

```
王梓博: "老陈，你咋XX了？"
陈汉升: "XX罢了。"
王梓博: "你XX挺XX的。"
陈汉升: "笑个屁。"或"去帮我XX。"
王梓博: "好好好。"
```

**使用时机**: 每章2-3次

### 组合4：女主管主角（傲娇）

```
女主: "你如果再XX，我就XX。"

女主: （得意）

陈汉升: "不用。"（拒绝）
女主: （倔强）还是给，然后"哼"一声走了
```

**使用时机**: 每2-3章1次

## 💡 第八部分：实战速查

### 需要快速制造冲突时:

```
→ 用"装逼打脸"流程
→ 对手说长句（装）
→ 主角说短句（痞）
→ 3-5个回合结束
```

### 需要推进感情线时:

```
→ 用"暧昧推进"流程
→ 制造肢体接触
→ 女主反应
→ 主角不纠缠
→ 保持张力
```

### 需要调节气氛时:

```
→ 用"损友互动"
→ 王梓博提问/吐槽
→ 陈汉升敷衍/指使
→ 轻松幽默
```

### 需要展示人物时:

```
→ 用对话代替描写
→ 3句话展现性格
→ 不要长篇介绍
```
