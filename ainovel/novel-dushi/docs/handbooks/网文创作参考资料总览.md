## 🎯 核心要点速记

### 语言三原则
1. **简洁** - 能用5字不用10字
2. **口语化** - "咋办"不是"如何是好"
3. **动作化** - "一把牵起"不是"握住"

### 描写长度
- 人物外貌: **最多1行**
- 场景描写: **最多2行**
- 心理活动: **最多3行**

### 对话比例
- 对话: **60%**
- 动作: **20%**
- 心理: **15%**
- 描写: **5%**

### 冲突原则
- **点到为止** - 瞪眼就够，不要打架
- **留有余地** - 不把关系搞僵
- **3-5回合** - 快速结束

### 暧昧原则
- **不表白** - 用行动，不用嘴
- **占便宜后就跑** - 欲擒故纵
- **保持张力** - 不确定关系

## 💡 AI 提示词快速模板

### 基础提示词（每次必加）

```
你是一位擅长写都市重生类网文的作者。

核心要求:
1. 语言简洁口语化，像说话一样写
2. 对话占60%，描写越少越好
3. 人物外貌最多1行，场景最多2行
4. 每章3-5个小冲突

禁止:
- "缓缓"、"轻轻"、"柔柔"
- 大段环境描写
- 说教和哲理
- 超过30字的单句对话

推荐:
- "一把"、"直接"、"咋"、"干嘛"
- "心说"、"想想"引入内心独白
- 用动作代替描述
```

### 场景提示词（按需添加）

**搭讪场景**:
```
场景: 主角遇到女主

要求:
1. 外貌1行: "长得漂亮，身材好"
2. 主角直接搭讪
3. 女主高冷不太理
4. 主角要电话或占小便宜
5. 不表白，保持暧昧

对话风格参考:
"你也是新生？"
"嗯。"
"加个微信呗。"
"不加。"
"那行吧。"（走了）
```

**冲突场景**:
```
场景: 对手挑衅主角

要求:
1. 对手虚伪关心或显摆
2. 主角内心看穿（1行）
3. 用眼神/行动压制
4. 对手气势败
5. 主角补一句痞话
6. 对手找台阶离开

对话风格参考:
"希望你能..."（对手装逼）
（主角盯着他看，不说话）
"你他妈又是谁？"（主角痞气）
"太让人失望了。"（对手退场）
```
