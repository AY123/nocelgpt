## 错误分类

### 错误1：Standard 版本不匹配
```
[error] pin @ _meta: Project pins Standard 2.0.0 but runtime targets latest (MAJOR mismatch)
```

**原因**: Registry 固定在 Standard 2.0.0，但 runtime 使用 latest

**修复**: 更新 `_meta/registry-version` 或使用 `--standard-version 2.0.0`

---

### 错误2-4：deprecated 字段不在 schema 中
```
[error] schema @ EVT-00001~00003: Additional properties are not allowed 
('deprecated_at', 'deprecated_reason' were unexpected)
```

**原因**: 我们添加的 `deprecated_at` 和 `deprecated_reason` 字段不在 Event schema 中

**修复方案**:
- **方案A**: 使用 schema 支持的 `status: deprecated`（已做）+ 在 `notes` 中记录原因
- **方案B**: 直接删除这3个旧事件（不再需要）

---

### 错误5-7：arc_metadata 字段不在 schema 中
```
[error] schema @ EVT-90001~90003: Additional properties are not allowed 
('arc_metadata' was unexpected)
```

**原因**: `arc_metadata` 是我们自定义的字段，不在 Event schema 中

**修复方案**:
- **方案A**: 使用 `notes` 字段标记（如 "候选卷级事件"）
- **方案B**: 直接删除这3个卷级事件
- **方案C**: 将卷级信息存储在 outline 或其他地方

### 错误8-13：tombstone 错误
```
[error] tombstone @ CHR-00001: reference to deprecated entity EVT-00001
[error] tombstone @ EVT-00001: reference to deprecated entity EVT-00002
...
```

**原因**: 
- 旧角色 CHR-00001~00002 引用了 deprecated 事件
- 旧事件之间相互引用（causes/effects）

**修复方案**:
- **方案A**: 删除所有旧事件和旧角色
- **方案B**: 修复引用关系
