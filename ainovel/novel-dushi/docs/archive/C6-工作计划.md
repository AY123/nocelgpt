**文档格式**:
```markdown
# Module: runtime.contract.production_state

## Class: ProductionState

Unified production state enum.

### States

- `GENERATED`: Chapter generated, awaiting review
- `NEEDS_REVISION`: Chapter needs revision
- `BLOCKED`: Chapter blocked
- `HUMAN_APPROVED`: Human approved
- `PUBLISHED`: Published
- `INVALIDATED`: Invalidated

### Methods

#### can_export() -> bool

Returns whether chapter can be exported.

**Returns**: `True` if state is HUMAN_APPROVED or PUBLISHED

**Example**:
```python
state = ProductionState.HUMAN_APPROVED
if state.can_export():
    export_chapter()
```
```
