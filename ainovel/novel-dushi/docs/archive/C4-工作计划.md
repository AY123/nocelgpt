### Task 4.2: 添加发布前验证（1天）

**目标**: 在发布前验证所有章节

**核心逻辑**:
```python
def validate_chapters_for_release(
    project_path: Path,
    chapter_numbers: List[int]
) -> tuple[bool, dict]:
    """
    发布前验证
    
    检查：
    1. 所有章节都存在
    2. 所有章节状态为 HUMAN_APPROVED 或 PUBLISHED
    3. 所有章节通过契约验证
    4. 章节之间连续性正确
    
    Returns:
        tuple[bool, dict]: (是否可以发布, 验证报告)
    """
    integration = create_integration(project_path)
    
    report = {
        'total_chapters': len(chapter_numbers),
        'passed_chapters': 0,
        'failed_chapters': 0,
        'errors': [],
        'warnings': []
    }
    
    for chapter_num in chapter_numbers:
        # 1. 检查状态
        state = load_chapter_state(chapter_num)
        if not state or not state.can_export():
            report['failed_chapters'] += 1
            report['errors'].append(
                f"第{chapter_num}章状态不允许发布: {state}"
            )
            continue
        
        # 2. 验证契约
        draft = load_chapter_draft(chapter_num)
        passed, result = integration.validate_chapter_draft(
            chapter_num,
            draft
        )
        
        if not passed:
            report['failed_chapters'] += 1
            report['errors'].extend(result['errors'])
        else:
            report['passed_chapters'] += 1
            if result.get('warnings'):
                report['warnings'].extend(result['warnings'])
    
    can_release = report['failed_chapters'] == 0
    return can_release, report
```

### Task 4.3: 集成到 Mint 流程（1天）

**目标**: 将验证集成到 Mint 主流程

**集成点**:
```python
def mint_release(
    project_path: Path,
    chapter_range: tuple[int, int],
    enable_validation: bool = True,  # 新参数
    force: bool = False  # 强制发布（跳过验证）
):
    """
    发布章节包
    
    流程：
    1. 收集章节
    2. 【新】发布前验证
    3. 打包
    4. 生成元数据
    5. 输出
    """
    
    # 收集章节
    chapters = collect_chapters(project_path, chapter_range)
    
    # 【集成点1】发布前验证
    if enable_validation and not force:
        can_release, report = validate_chapters_for_release(
            project_path,
            [ch.number for ch in chapters]
        )
        
        if not can_release:
            logger.error("发布验证失败")
            logger.error(f"错误: {report['errors']}")
            
            # 决策：是否继续？
            if not force:
                raise ReleaseValidationError(report)
        
        # 生成验证报告
        save_validation_report(report)
    
    # 打包
    package = create_package(chapters)
    
    # 【集成点2】更新章节状态为 PUBLISHED
    if enable_validation:
        for chapter in chapters:
            update_chapter_state(
                chapter.number,
                ProductionState.PUBLISHED
            )
    
    # 输出
    save_package(package)
    
    logger.info(f"发布完成: {len(chapters)}章")
```

**实现步骤**:
1. 在 Mint 主函数开始处添加验证

3. 验证成功后更新状态
4. 生成验证报告
5. 添加集成测试
