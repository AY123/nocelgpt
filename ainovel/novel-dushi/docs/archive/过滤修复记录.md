# _ordered_event_ids 修复记录

**时间**: 2026-09-08 14:50  
**问题**: deprecated 和 arc_metadata 事件未被过滤

---

## 问题诊断

### 原始行为
`_ordered_event_ids` 返回所有 EVT-* 事件，包括：
- EVT-00001~00003 (status: deprecated)
- EVT-90001~90003 (arc_metadata: true)
- EVT-90004~90033 (正常章节事件)

### 导致的问题
1. plan_chapters() 返回 36个章节（应该是 30个）
2. 包含已弃用事件
3. 包含卷级事件
4. 所有章节验证失败

---

## 修复方案

### 修改位置
`runtime/memory/state.py:35-47`

### 修改内容
在 `_ordered_event_ids` 中添加过滤：

```python
# Skip inactive events (deprecated, tombstoned)
if rec.get("status") in _INACTIVE:
    continue

# Skip arc metadata events (not for chapter generation)
if rec.get("arc_metadata"):
    continue
```

---

## 预期效果

过滤后应该只返回：
- EVT-90004~90033 (30个章节事件)
- 排除 EVT-00001~00003 (deprecated)
- 排除 EVT-90001~90003 (arc_metadata)
