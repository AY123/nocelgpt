### Task 5.3: 统一状态判断（0.5天）

**目标**: 将所有状态判断统一使用 ProductionState

**示例转换**:

**Before**:
```python
# 分散的判断逻辑
if publish_readiness.get('recommendation') == 'publish':
    can_publish = True
elif commercial_verdict == 'approved':
    can_publish = True
else:
    can_publish = False
```

**After**:
```python
# 统一使用 ProductionState
state = ProductionState(chapter_data['production_state'])
can_publish = state.can_export()
```

**需要更新的判断**:
1. 发布判断 → `state.can_export()`
2. 继续下一章判断 → `state.can_proceed_next()`
3. 修改判断 → `state.can_revise()`
4. 发布判断 → `state.can_publish()`

**实现步骤**:
1. 找到所有判断逻辑
2. 替换为 ProductionState 方法
3. 测试每个替换
4. 保留旧逻辑作为备用（注释掉）

**验收标准**:
- ✅ 所有判断统一
