### Task 3.1: 添加契约集成钩子（2天）

**目标**: 在 Serial 的关键位置添加契约集成钩子

**修改文件**: `runtime/serialize/loop.py`

**核心改动**:
```python
def run_serial(..., enable_contract_integration: bool = False):
    # 1. 创建契约集成
    contract_integration = None
    if enable_contract_integration:
        contract_integration = create_integration(
            project_path=Path(project_path),
            enable_contract_integration=True
        )
        if contract_integration:
            contract_integration.initialize_state()
    
    # 2. 主循环
    for chapter_num in range(start_chapter, ...):
        # 2.1 章节入口验证
        if contract_integration:
            can_proceed, errors = contract_integration.validate_chapter_entry(
                chapter_num,
                previous_state=previous_production_state
            )
            if not can_proceed:
                logger.error(f"第{chapter_num}章被阻塞: {errors}")
                # 设置 BLOCKED 状态并跳过
                continue
        
        # 2.2 生成章节（现有逻辑）
        draft = generate_chapter(...)
        
        # 2.3 契约验证
        if contract_integration:
            passed, result = contract_integration.validate_chapter_draft(
                chapter_num,
                draft_text=draft.content
            )
            if not passed:
                logger.warning(f"第{chapter_num}章契约验证失败: {result}")
                # 设置 BLOCKED 状态
                draft.production_state = ProductionState.BLOCKED
        
        # 2.4 更新状态
        if contract_integration:
            new_state = contract_integration.update_state_from_draft(
                chapter_num,
                draft_text=draft.content
            )
```

**实现步骤**:
1. 添加 `enable_contract_integration` 参数
2. 在循环开始前初始化集成
3. 在章节生成前验证入口条件
4. 在章节生成后验证契约
5. 根据验证结果设置状态

**验收标准**:
- ✅ 参数可以启用/禁用契约集成
- ✅ 默认不启用（向后兼容）
- ✅ 启用时自动验证

### Task 3.3: 实现阻塞机制（1天）

**目标**: 实现无法跳过阻塞章节的机制

**核心逻辑**:
```python
def can_generate_chapter(chapter_num: int, project_path: Path) -> bool:
    """
    检查是否可以生成指定章节
    
    条件：
    1. 如果是第1章，总是可以生成
    2. 如果是第N章（N>1），上一章必须是 HUMAN_APPROVED 或 PUBLISHED
    """
    if chapter_num == 1:
        return True
    
    # 加载上一章状态
    prev_final_path = project_path / f"chapter-final-{chapter_num-1:05d}.json"
    if not prev_final_path.exists():
        return False
    
    with open(prev_final_path) as f:
        prev_final = json.load(f)
    
    prev_state = ProductionState(prev_final.get('production_state', 'generated'))
    return prev_state.can_proceed_next()
```

**实现步骤**:
1. 实现 `can_generate_chapter()` 函数
2. 在 Serial 循环中调用
3. 阻塞章节跳过生成
4. 记录阻塞原因

**验收标准**:
- ✅ 第1章总是可以生成
- ✅ 第N章需要第N-1章通过
- ✅ BLOCKED 章节无法继续

## 🚨 风险和应对

### 风险1: 破坏现有功能
**应对**:

- 保留所有旧逻辑

- 只在启用时执行
- 缓存契约对象

**应对**:
- 旧字段标记为 advisory
- 新字段是唯一决策源
- 渐进式迁移
