## 🚀 使用示例

### 完整的章节生成流程

```python
from pathlib import Path
from runtime.serialize.contract_integration import create_integration
from runtime.contract import ProductionState

# 1. 创建集成
integration = create_integration(
    project_path=Path("novel-dushi"),
    enable_contract_integration=True
)

# 2. 逐章生成
for chapter_num in range(1, 31):
    # 2.1 验证入口条件
    if chapter_num > 1:
        prev_state = load_previous_state(chapter_num - 1)
        can_proceed, errors = integration.validate_chapter_entry(
            chapter_num,
            previous_state=prev_state
        )
        
        if not can_proceed:
            print(f"❌ 第{chapter_num}章被阻塞: {errors}")
            break
    
    # 2.2 生成草稿
    draft = generate_chapter_draft(chapter_num)
    
    # 2.3 验证契约
    passed, result = integration.validate_chapter_draft(
        chapter_num,
        draft_text=draft
    )
    
    if not passed:
        print(f"❌ 第{chapter_num}章验证失败: {result['errors']}")
        save_with_state(draft, ProductionState.BLOCKED)
        break
    
    # 2.4 更新状态
    new_state = integration.update_state_from_draft(
        chapter_num,
        draft_text=draft
    )
    
    # 2.5 保存
    save_with_state(draft, ProductionState.GENERATED)
    print(f"✓ 第{chapter_num}章生成完成")
```

## 📈 架构改进

### Before C2
```
Serial 生成 → [无契约检查] → 直接保存
              [无状态验证]
              [无阻塞机制]
```

### After C2
```
Serial 生成 → ContractIntegration
              ├─ 验证章节入口 (上一章状态检查)
              ├─ 验证契约 (主角名、日期、地点)
              ├─ 验证连续性 (时间、人物、状态)
              └─ 设置 ProductionState
                 ├─ BLOCKED (阻塞，无法继续)
                 ├─ GENERATED (生成，待审核)
                 └─ HUMAN_APPROVED (通过，可继续)
```
