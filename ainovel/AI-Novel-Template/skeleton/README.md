# skeleton/ — intentionally not a static skeleton

This directory is a **placeholder**, kept empty on purpose.

The Project skeleton is **not** stored here as static files. It is generated by
[`../tools/init_project.py`](../tools/init_project.py), which reads the
Standard's generated `catalog.json` and materializes the registry tree from it.
Storing a static copy here would create a second source of the directory layout
that could drift from the catalog — exactly what the catalog exists to prevent
(ADR-007).

If a future need arises for static, non-derivable scaffold files (e.g. a default
`.gitignore`, license, or editor config that is *not* derived from the catalog),
they belong here. Until then this directory stays empty by design.
