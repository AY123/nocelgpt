## 🎯 最佳方案：四层金字塔大纲法

### 为什么推荐？

**单一方法的局限**:
- **三幕式**: 只管开头中间结尾，不管章节衔接
- **九线法**: 管多线并行，但不管节奏爽点
- **升级流**: 管爽点节奏，但不管世界观一致性

**四层金字塔的优势**:
- ✅ 结合所有方法的优点
- ✅ 专为AI长篇设计
- ✅ 解决章节衔接问题
- ✅ 管理百万字设定一致性

### 四层结构详解

```
第一层：雪花法核心（战略层）
├─ 一句话梗概
├─ 三幕框架
├─ 角色设定
├─ 世界观核心
└─ 主题基调

第二层：九线法规划（战术层）
├─ 主线：复仇与成长
├─ 成长线：曜能升级
├─ 反派线：二叔对抗
├─ 情感线：镜见川
├─ 悬念线：矿心身世
├─ 世界线：世界观展开
├─ 团队线：伙伴收集
├─ 支线：清远旧事
└─ 升级线：境界突破

第三层：升级流节奏（节奏层）
├─ 每20-30章一个大循环
├─ 目标 → 冲突 → 升级 → 奖励
├─ 爽点密度控制
└─ 高潮低谷交替

第四层：章节级规划（执行层）⭐关键
├─ 每章4要素
│  ├─ 目标（推进什么）
│  ├─ 冲突（遇到什么）
│  ├─ 钩子（章末悬念）
│  └─ 承接（如何衔接下一章）
└─ 章节间预设承接点
```

## 📋 章节衔接的核心技巧

### 每章必备4要素

**1. 目标（What）**
```
本章要推进什么？
- 段奕尘要逃离矿场
- 镜见川要测试段奕尘
- 揭示曜能种的秘密
```

**2. 冲突（Conflict）**
```
遇到什么阻碍？
- 马平追捕
- 曜能失控
- 身份即将暴露
```

**3. 钩子（Hook）**
```
章末留什么悬念？
- 类型：悬念型、冲突型、威胁型、反转型
- 示例："而这一次，段奕尘已经无路可退。"
```

**4. 承接（Bridge）**
```
如何衔接下一章？
- 时间：三天后/同时/片刻后
- 地点：矿井深处/另一边
- 视角：段奕尘/镜见川
- 悬念：那双眼睛的主人是谁？
```

### 承接点预设示例

**Ch93末尾（已修复）**:
```
他来了。
而这一次，段奕尘已经无路可退。
← 预设承接点：危机、对峙
```

**Ch94开头**:
```
荧惑的指尖悬在晶阵核心上方...
← 承接：危机场景，时间同步
```
