## 🔍 需要审核的核心问题

### 1. AI 味道检测 ⭐⭐⭐⭐⭐
**问题表现**:
- ✗ 重复性表达（"他深吸一口气"、"眼神一凛"）
- ✗ 机械式对话（过于正式，缺乏口语化）
- ✗ 套路化描写（"瞳孔一缩"、"心头一震"）
- ✗ 情感单一（只有"震惊"、"警惕"）
- ✗ 缺乏细节（笼统描述，不够生动）

**审核方法**:
1. 人工抽样阅读 15-20 章
2. 标记 AI 痕迹明显的段落
3. 用户测试反馈

**是否修复**: ⚠️ **根据用户反馈决定**
- 如果用户测试反馈"AI 味道明显" > 50%，必须修复
- 如果 < 30%，可以接受
- 修复方式：人工润色重写

---

### 2. 前后连贯性 ⭐⭐⭐⭐⭐
**问题表现**:
- ✗ 角色性格前后不一致
- ✗ 情节设定自相矛盾
- ✗ 人物关系混乱
- ✗ 世界观设定冲突
- ✗ 伏笔未回收或遗忘

**审核方法**:
1. 跨章节对比阅读
2. 核对角色设定表
3. 梳理情节线
4. 检查关键转折点

**是否修复**: ✅ **必须修复**
- 连贯性问题严重影响阅读体验
- 修复方式：找出矛盾处，统一设定
- 优先级：高

---

### 3. 任务漂移 ⭐⭐⭐⭐
**问题表现**:
- ✗ 主线任务不清晰或被遗忘
- ✗ 支线过度发散
- ✗ 角色目标模糊
- ✗ 故事方向偏离原定计划

**审核方法**:
1. 对照 outline 和 rolling plan
2. 检查主线推进
3. 验证角色目标
4. 确认关键情节点

**是否修复**: ⚠️ **视严重程度**
- 轻度漂移：可以接受（故事有机发展）
- 严重漂移：需要修正（回归主线）
- 修复方式：调整偏离章节，强化主线

---

### 4. 对话自然度 ⭐⭐⭐⭐
**问题表现**:
- ✗ 对话过于书面化
- ✗ 缺乏个性化语气
- ✗ 信息堆砌（对话只为传递信息）
- ✗ 缺乏口语化表达

**审核方法**:
1. 朗读对话段落
2. 检查是否符合人物性格
3. 用户测试反馈

**是否修复**: ⚠️ **根据反馈决定**
- 明显不自然的对话需要重写
- 修复方式：增加口语化、个性化

---

### 5. 情节节奏 ⭐⭐⭐
**问题表现**:
- ✗ 节奏拖沓（过多无关描写）
- ✗ 节奏过快（缺少铺垫）
- ✗ 高潮点设置不合理
- ✗ 转折生硬

**审核方法**:
1. 章节长度分析
2. 关键情节密度检查
3. 用户阅读体验反馈

**是否修复**: ⚠️ **根据反馈决定**
- 明显拖沓的章节需要删减
- 过快的情节需要补充铺垫

---

### 6. 文笔质量 ⭐⭐⭐
**问题表现**:
- ✗ 错别字
- ✗ 病句
- ✗ 重复用词
- ✗ 描写不生动

**审核方法**:
1. 人工校对
2. 用户反馈

**是否修复**: ✅ **错别字、病句必须修复**
- 基本错误影响阅读体验
- 描写质量可以根据反馈决定
