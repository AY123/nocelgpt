# R1 — 现实基线报告（Reality Baseline）

北极星：从 1–3 本参考小说 → 稳定产出前 30 章 → 真实网文编辑判断有无平台试水价值。
本报告是 R1 的核心交付物：**机器信号 vs 编辑盲评的逐项对照**。

- 样本：genesis-pilot 的 **3 章真实 DeepSeek(deepseek-v4-pro)正文**（ch1=7637字 / ch2=3888字 / ch3=6408字），非确定性 stub。
- 编辑：以中文商业网文编辑身份盲评（AI 顾问担任；真人编辑复评是 R1 的后续增强）。
- 方法：先读全文按商业轴打分，再与已持久化的机器信号（density/ai_taste/end_hook/length/pacing_peak/m7/reference_gap）对齐，重点找**机器测不到、误报、漏报**的三类缺口——这正是 R2 要校准的仪器偏差方向。

作品速写：都市异能/悬疑「梦墟」——主角周洛铭车祸后觉醒“触碰他人梦境”的金手指（带记忆遗失代价），卷入潜梦者猎杀与父亲遗留的“梦墟”阴谋。

## 二、机器信号 vs 编辑判断：三类缺口（R1 的核心产出）

### 缺口 A — 机器**完全测不到**：生成断裂/错字（致命，最高优先）

三章全部出现文本断裂，真人一眼出戏，但**所有机器信号（density/ai_taste/length/hook）全绿或未报**：

- ch1：`和前天一一样。和车？/ 祸后睁眼` —— “一一样”叠字 + “车祸”被劈成“和车？/祸”跨行断裂。
- ch2：`灰蒙蒙的絮状物像某种活物，缠？/ 绕在路灯杆上` —— “缠绕”被劈成“缠？/绕”。
- ch3：`现实里林墨渊不会把右手插？/ 在别人的太阳穴里` —— “插在”被劈成“插？/在”。

**根因推断**：疑似流式生成/分段拼接处的分隔符或标点注入 bug（`？`+换行插进词中）。这是**生产管线缺陷**，不是文风问题。
**为什么机器漏报**：density 测对白比、ai_taste 测句式重复、length 测字数——没有一个检测器读“词是否被标点/换行劈断”。
**R2 动作**：新增一个确定性“文本完整性”检测器（词内标点/叠字/跨行断词），成本极低、召回极高，且这是 gate 级（真人出戏=劝退）。**这是 R1 发现的最高价值单点。**

### 缺口 B — 机器**误报方向**：ai_taste 对 ch1「同头排比」报警，但真实致命项在别处

- ch1 ai_taste 报“连续5句以‘他’开头的排比，机器味重”——编辑视角：这段（回忆办公室/父亲电话）**恰恰是文学性较强的排比蒙太奇，读感不差**。机器把“有意的排比”误判为“AI味”。
- 而真正的 ch1 致命项（对白仅2.7%、7637字纯叙述注水、生成断裂）里，只有“对白过低”被 density 抓到，注水超长被 length 抓到，**断裂完全漏掉**。

**结论**：ai_taste 的“同头句”规则在“抒情排比”上有**假阳性**；这正是 R2 要用编辑评分校准的偏差方向——不是删掉规则，而是学出“何时排比是文学、何时是AI味”。

### 缺口 C — 机器**漏报**：章末钩子“有/无”是二值，测不出“钩力强弱”

- end_hook 对三章都报“章末留有钩子”（全绿），但编辑评分 ch2=5（旧疤显字·强钩）、ch3=3.5（情感问句·弱钩）——**机器分不出强弱**。
- pacing_peak：ch1=75、ch2=75、ch3=85，与编辑的“钩力/节奏”判断**不一致**（ch1 编辑给节奏2.5，机器峰值75偏高）。

**结论**：钩子/节奏信号是“存在性”而非“强度”信号，无法驱动“把弱钩改强”的修订。R2 需用 pairwise 评委（已存在，比绝对评委可靠）在钩力维度做相对判断。

## 三、机器信号可信度分级（喂给 R2 校准）

| 信号 | 与编辑判断一致性 | R2 处置 |
|---|---|---|
| length（字数/超长） | **高**（ch1/ch3 超长=真拖沓） | 保留，可作强 advisory |
| density（对白比/信息密度） | **中高**（ch1 低对白=真问题） | 保留，阈值可信 |
| ai_taste（AI味/句式） | **中低**（对文学排比假阳性） | 需编辑评分校准，勿直接驱动改写 |
| end_hook（钩子有无） | **低**（测不出强弱） | 升级为强弱信号或改用 pairwise |
| pacing_peak（情绪峰值） | **低**（与编辑节奏判断背离） | 需校准或降权 |
| m7（原创性/红线） | 未触发（本样本无参考语料对齐） | 需真实参考语料重测 |
| **文本完整性** | **缺失**（最致命的项无检测器） | **R2 新增，gate 级** |

## 四、R1 结论与对 R2 的移交

1. **质量天花板**：真实 DeepSeek 正文的**故事/结构/商业底子达到“可试水”水位**，但**生产管线缺陷（生成断裂）+ 节奏超长**使其“不能直接发”。天花板不在“会不会写”，在“产线有没有把写好的正文完整、节制地交付出来”。
2. **仪器偏差方向已测出**：length/density 可信；ai_taste 有假阳性；hook/pacing 是二值/背离；**文本完整性是最致命的盲区**。
3. **移交 R2 的具体任务**（按价值排序）：
   - R2-a（最高）：新增确定性**文本完整性检测器**（词内标点/叠字/断词），gate 级；同时定位并修复生成断裂的产线根因。
   - R2-b：用本报告的编辑评分做**校准集**，学 ai_taste / hook / pacing 的偏差方向；优先用 **pairwise 评委**（记忆 `pairwise-character-judge`，比绝对评委可靠）。
   - R2-c：点火 P5.6 reader-signal 存储，把编辑评分作为第一批“真实信号”写入。

> R1 用 3 章跑通了方法论，零新增大模块（纯读取+对照）。是否扩到 30 章、是否引入真人编辑复评，取决于 R2 校准后信号是否可信——若可信，30 章基线可由机器信号自动生成，只需真人抽检。
