## 4. 使用规则

- 事实与规划分离。
- 规划与执行分离。
- 规范与样例分离。
- 发布与草稿分离。
- 模拟信号与真实平台信号分离。
- 未校准信号不得用于强决策。

## 6. 结论

这套文档体系的目标很简单：

- 让人知道先看什么
- 让执行知道按什么做
- 让事实、规划、执行、评审、发布、学习不互相混淆
