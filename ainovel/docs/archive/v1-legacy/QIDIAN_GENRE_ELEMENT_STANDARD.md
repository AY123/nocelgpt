# 起点题材要素规范（九题材专业报告）

> 文档定位：`QIDIAN_COMMERCIAL_NOVEL_STANDARD.md` 的**题材维度补集**。前者讲跨题材恒定的商业骨架（黄金三章、净推进、承诺兑现、钩子），本文讲**同一套骨架在九个题材上的参数差异**：题材承诺、必备要素、开篇打法、节奏区间、专属雷区。
>
> 覆盖题材：玄幻、奇幻、武侠、仙侠、都市、历史、游戏、科幻、诸天无限。
>
> 使用范围：Genesis 选题、Market Position、Novel Brain、Outline DSL、Long-Arc、Narrative Mandate、Chapter IR、Director、Quality Center、Reference Band、发布前自检。

## 0. 证据边界（必读）

本文的证据等级必须显式区分，不得混用：

| 等级 | 含义 | 本文标记 |
|---|---|---|
| A 仓库事实 | 代码/契约中可验证，附 `file:line` | 直接给路径 |
| B 行业共识 | 网文编辑与作者群体长期公认的结构规律 | 「共识」 |
| C 经验区间 | 数量级参考，个体方差极大 | 「经验区间」 |
| D 待验证 | 本项目尚无数据支撑，需真实平台信号校准 | 「待验证」 |

**本文撰写时未能完成联网检索**（工具连续失败/被拒），因此不含 A 级以外的外部引用链接。所有题材要素为 B/C 级：来自对该题材长期作品结构的归纳，不是对特定榜单的实时统计。

由此产生三条硬约束：

1. 本文所有数字（章字数、免费章数、兑现间隔）均为 **C 级经验区间**，只能作为生成约束的初始值，**不得**当作校准后的真值写进任何 Gate。
2. 本文的题材判断在拿到真实 `ReaderSignal`（首订、追读、掉读章）之后必须被复核；冲突时以真实数据为准。
3. 遵循 ADR-003：题材要素检查一律 `gating=false`。唯一可 Gate 的仍然是确定性硬红线。

## 1. 骨架恒定，参数可变

九个题材共享同一条商业漏斗（点击 → 前三章留存 → 免费追读 → 付费转化 → 长期稳定），差异不在**要不要**这些环节，而在**用什么兑现**。

跨题材**恒定**（写进通用规范，不按题材分叉）：

- 主角主动性：每章至少一次由主角推动的变化；
- 章节净推进：章末状态 ≠ 章初状态；
- 承诺—兑现账本：小承诺 1–3 章、中承诺 5–15 章；
- 钩子来自本章因果，且类型不连续重复；
- 对手会学习；
- 设定服务冲突，不停下剧情讲百科。

按题材**变化**的七个参数轴（这才是本文的正文）：

| 参数轴 | 说明 | 差异示例 |
|---|---|---|
| `promise` 题材承诺 | 读者点开时买的是哪种情绪 | 玄幻=变强碾压；历史=改变已知结局 |
| `mechanism` 核心机制形态 | 金手指长什么样 | 仙侠=功法/丹道；游戏=面板与副本规则 |
| `ladder` 进阶阶梯 | 什么在涨 | 玄幻=境界；都市=财富与圈层；历史=官阶 |
| `map` 地图扩张路径 | 舞台如何逐层放大 | 武侠=镇→州→江湖；科幻=舰→星系 |
| `payoff_mix` 爽点配比 | 感官/能力/信息/关系/结构五类的权重 | 玄幻偏能力；权谋偏信息 |
| `cadence` 节奏参数 | 章长、免费章数、大兑现间隔 | 快节奏玄幻 vs 沉浸历史 |
| `hazard` 专属雷区 | 该题材独有的失败模式与合规风险 | 历史=历史观与真实人物；游戏=版权指涉 |

后续每一节按这七轴组织，末尾给出「映射到本项目哪个字段」。

## 2. 玄幻

起点男频第一大类，也是本项目当前默认目标题材。

### 2.1 题材承诺

读者买的是**成长权力感**：从被踩到踩人，且这个过程有清晰刻度。核心情绪是"我能看见自己变强"。

不可容忍（弃书雷点）：
- 前三章没有力量刻度，读者不知道主角现在几档；
- 主角长期挨打不还手（憋屈期超过 2 章无局部进展）；
- 境界名词一次性倾泻十几个；
- 打脸对象换皮重复，敌人不会学习。

### 2.2 必备要素

| 轴 | 玄幻取值 |
|---|---|
| `mechanism` | 解析型/吞噬型/传承型/系统型金手指；必须前三章生效一次 |
| `ladder` | 境界阶梯（3–9 大境，每境可分小段），**必须在第一章给出可感知的相对位置** |
| `map` | 个人处境 → 家族/宗门 → 城/域 → 大势力 → 世界真相 |
| `payoff_mix` | 能力爽 40% / 感官爽 25% / 关系爽 15% / 信息爽 12% / 结构爽 8%（前 30 章；后期结构爽须上升） |

境界体系设计的三条硬要求（共识）：
1. **可数**：读者能说出主角"第几档，共几档"；
2. **有质变**：跨境不只是数值，须解锁新玩法（如从御物到破空）；
3. **有代价**：突破需要资源/风险/时间，否则升级失去张力。

### 2.3 开篇打法（黄金三章的玄幻特化）

- 第 1 章：**废柴/退化/剥夺**式开局最稳（被夺资格、修为跌落、家族除名），因为它同时给出力量刻度与迫近损失；
- 第 1 章 300 字内必须出现一次力量对比（谁比主角强多少）；
- 第 2 章：金手指首次使用要**解决一个具体的小问题**（不是演示奇观）；
- 第 3 章：第一次主动战胜同阶或越阶对手，且胜利来自机制+人格，不是巧合。

### 2.4 子类型

| 子类 | 特征 | 差异点 |
|---|---|---|
| 宗门流 | 内外门、长老、资源分配 | 冲突来自派系与考核，节奏最稳 |
| 无敌流 | 开局即强 | 爽点靠"反应"而非"成长"，需大量旁观者视角 |
| 家族流 | 以家族为单位扩张 | 阶梯是家族地位，管理与分配戏多 |
| 洪荒/神话流 | 高开局、神话背景 | 需处理既有神话设定的一致性 |
| 西玄（玄幻+西方框架） | 与奇幻交叉 | 注意译名腔（见 §3.6） |

### 2.5 节奏（经验区间）

- 单章 2000–3000 字（起点均值，本项目 `chapter_length` 分角色区间已实现）；
- 免费 20–40 章上架；
- 大兑现每 20–30 章一次，小兑现每 3–5 章；
- 第一卷 80–120 章。

### 2.6 专属雷区

- **无限套娃升级**：境界只加不变玩法；
- **刻度通胀**：第 30 章就把开篇设定的最高境界打穿；
- **旁观者震惊代替爽点**：只有"众人哗然"没有实际损失确认。

### 2.7 映射

`novel_brain.genre.primary=玄幻` → `long_arc.progression_ladders` 填境界阶梯 → `chapter_objective.payoff_target` 绑定当前档位 → `reference` 锚用同题材参考小说测 band。

## 3. 奇幻

与玄幻同源但世界语法不同：玄幻的秩序是"境界"，奇幻的秩序是"体系/职业/序列"。

### 3.1 题材承诺

读者买的是**异世界规则的探索快感 + 体系化成长**。相较玄幻，奇幻读者对"设定自洽"的容忍下限更高、要求更严：世界必须像真的在运转。

弃书雷点：
- 译名腔（"哦，我的老伙计"式对白）；
- 术语过载：序列、位阶、学派、教会、货币一次性砸出；
- 魔法没有代价，等于换皮玄幻；
- 世界只有主角在活动，城邦/教会/公会没有自己的日程。

### 3.2 必备要素

| 轴 | 奇幻取值 |
|---|---|
| `mechanism` | 序列/位阶晋升 + 仪式材料 + 失控代价（"诡秘"式体系是当前最强模板） |
| `ladder` | 职业阶位（学徒→正式→大师）或序列（9→1），**每阶须有名字与门槛** |
| `map` | 个人 → 学院/公会/教会 → 城邦 → 王国 → 神秘学真相 |
| `payoff_mix` | 信息爽 30% / 能力爽 25% / 结构爽 20% / 关系爽 15% / 感官爽 10% |

奇幻的差异化核心是**代价机制**：力量必须以理智、寿命、人性、负债或身份为抵押。无代价的奇幻会退化成低配玄幻。

### 3.3 开篇打法

- 第 1 章：**穿越者视角/失忆者视角**用于合法地解释世界，但解释必须由"当下危险"逼出来，不能主动科普；
- 前三章只允许引入 **1 套**体系术语（≤5 个专名）；
- 第 2 章：仪式或能力首次使用，同时暴露代价（这是奇幻区别于玄幻的关键差异点）；
- 第 3 章：用规则而不是力量赢一次（智性胜利），确立"这本书要动脑"的承诺。

### 3.4 子类型

| 子类 | 差异点 |
|---|---|
| 西方奇幻史诗 | 群像与势力战争，主角成长慢，需强配角线 |
| 学院流（剑与魔法） | 考核/同窗/导师构成天然节奏器，最易上手 |
| 克苏鲁 + 规则怪谈 | 核心是"规则条文"本身，爽点=解读并利用条文；恐怖需具体不能只氛围 |
| 神话奇幻 | 借用现成神话，注意宗教敏感与设定一致性 |
| 黑暗奇幻 | 调性沉重，付费转化需额外的希望锚点 |
| 蒸汽朋克/序列体系 | 时代质感 + 体系晋升双卖点，写作成本最高 |

### 3.5 节奏（经验区间）

- 单章 2500–3500 字（世界描写需要空间）；
- 免费 30–50 章（体系铺垫更长）；
- 大兑现每 25–35 章；
- 第一卷 100–150 章。

### 3.6 专属雷区

- **伪西幻**：地名人名换成音译，行为逻辑仍是中式宗门；
- **体系写在纸上**：序列表格很漂亮，正文只用到前两阶；
- **神秘感耗尽**：过早解释终极真相，后续无以为继；
- 宗教/族群指涉：教会、异端、圣战等设定须虚构化，避免映射现实宗教。

### 3.7 映射

`brain.genre.primary=奇幻` + `secondary=[克苏鲁]` → `long_arc.progression_ladders` 用序列命名 → `chapter_ir` 的 `structural_patterns` 记录"代价触发点" → `forbidden_style` 必须写入「译名腔」「术语倾泻」。

## 4. 武侠

九题材中商业难度最高的一类：读者群忠诚但规模小于玄幻，且对文风有独立要求。

### 4.1 题材承诺

读者买的是**江湖秩序中的个人意志**：恩怨、道义、招式美感、江湖人情。核心情绪不是"变强"而是"痛快"与"侠气"。

弃书雷点：
- 武功变成境界数字（把武侠写成玄幻）；
- 招式无形象（只说"一掌打出"不写招式质感）；
- 江湖没有规矩（帮派、镖局、官府、门派不构成约束）；
- 主角无侠义底线却仍被当正面人物写。

### 4.2 必备要素

| 轴 | 武侠取值 |
|---|---|
| `mechanism` | 武学秘籍/内功心法/招式创新/兵器；**须可视化**（招式有名有形有克制关系） |
| `ladder` | 江湖名位（无名→成名→一流→绝顶）＋ 内功层数；不宜超过 5 档 |
| `map` | 小镇 → 州府 → 门派 → 江湖格局 → 朝廷/塞外 |
| `payoff_mix` | 关系爽 30% / 能力爽 25% / 感官爽 20%（打斗美感）/ 信息爽 15% / 结构爽 10% |

武侠特有的必备要素是**江湖规矩**：比武不杀、镖不失手、门派辈分、黑白两道分际。规矩是冲突的来源，也是主角选择的重量所在。

### 4.3 开篇打法

- 第 1 章：**血仇/夺秘/落难**三种开局最稳，且必须给出具体的江湖坐标（哪一年、哪个帮、谁的地盘）；
- 打斗必须在第 1 章出现，且写出招式质感（武侠的第一章是"文风试读章"）；
- 第 2 章：得到武学但同时得到麻烦（秘籍必然引来追索）；
- 第 3 章：第一次凭武功与心智赢，并因此获得"江湖名声"这一资源。

### 4.4 子类型

| 子类 | 差异点 |
|---|---|
| 传统武侠 | 重人情与文风，节奏最慢，需极强笔力 |
| 新武侠/爽武 | 加快节奏、强化打脸，向玄幻靠 |
| 武侠 + 系统 | 用面板解决"武功不可量化"的问题，读者接受度高但易失侠味 |
| 江湖经营 | 开镖局/客栈/门派，节奏由经营循环提供 |
| 武侠悬疑 | 以案件推动，天然解决"没有主线"问题 |

### 4.5 节奏（经验区间）

- 单章 2000–3000 字；
- 免费 20–35 章；
- 大兑现每 15–25 章（比玄幻更密，因为江湖恩怨兑现窗口短）；
- 第一卷 60–100 章。

### 4.6 专属雷区

- **玄幻化**：内功变灵气、江湖变宗门、名位变境界，题材承诺失效；
- **打斗流水账**：只有动作没有攻防意图与心理；
- **配角工具化**：江湖题材尤其依赖群像，配角必须有自己的恩怨；
- 文风漂移：白话与半文言混用不稳定（本项目 register lock 只锁语言，不锁语域，见 §12 缺口）。

### 4.7 映射

`brain.writing_style.voice` 须显式写入"半文言/白话"选择；`speech_profile` 六轴对武侠收益最大（江湖人物口吻差异明显）；`_MALE_LEAN` 目前**不含武侠**，是必须修的缺陷（见 §12.1）。

## 5. 仙侠

与玄幻最易混淆，但承诺不同：玄幻卖"变强"，仙侠卖"求道"——长生、天道、逆天。

### 5.1 题材承诺

读者买的是**修道者对抗天地规则的孤高感**，以及漫长时间尺度带来的宿命感。核心情绪是"逆天而行"。

弃书雷点：
- 只有升级没有道心（修仙变成打怪刷级）；
- 时间尺度失真（闭关十年却与凡人恩怨纠缠）；
- 仙门只有考核没有清规；
- 长生的代价从不体现（亲友衰老、人性剥离全不写）。

### 5.2 必备要素

| 轴 | 仙侠取值 |
|---|---|
| `mechanism` | 功法/丹道/炼器/阵法/神通；须与"资源稀缺"强绑定（灵石、灵脉、寿元） |
| `ladder` | 炼气—筑基—金丹—元婴—化神…（读者熟悉的公版阶梯，**不建议自创全新命名**） |
| `map` | 凡俗 → 宗门 → 修真界域 → 上界/仙界 → 天道真相 |
| `payoff_mix` | 能力爽 30% / 信息爽 25% / 结构爽 20% / 感官爽 15% / 关系爽 10% |

仙侠三个不可省的要素：
1. **寿元与时间**：修士的时间观必须与凡人不同，且这个差异要产生剧情后果；
2. **资源稀缺**：修炼靠资源，资源靠争夺，这是仙侠冲突的第一引擎；
3. **道心/取舍**：主角在长生与人情之间必须真的付出过一次代价。

### 5.3 开篇打法

- 第 1 章：**凡人入道**（凡人流）或**重生归来**两种开局最稳；
- 凡人流开篇要给出"修仙世界的残酷定价"（一颗丹药等于全家性命）；
- 第 2 章：第一次修炼收益必须具体（几天筑基、多长寿元、什么感知变化）；
- 第 3 章：用修为解决一个凡俗层面的压迫，完成"跨阶层"的第一次爽点。

### 5.4 子类型

| 子类 | 差异点 |
|---|---|
| 正统仙侠 | 重道韵与文风，节奏慢，需意境描写 |
| 凡人流 | 谨慎主角、资源精算、长线；对逻辑一致性要求最高 |
| 散修流 | 无宗门庇护，冲突密度高，自由度大 |
| 洪荒/神话仙侠 | 高开局、借用既有神系；需处理"已知结局"的期待管理 |
| 宗门经营仙侠 | 与领主流交叉，节奏由建设循环提供 |

### 5.5 节奏（经验区间）

- 单章 2500–3500 字（意境描写占位）；
- 免费 25–45 章；
- 大兑现每 25–40 章（时间尺度长，兑现窗口相应放宽）；
- 第一卷 100–150 章。

### 5.6 专属雷区

- **仙侠外衣玄幻内核**：把宗门写成公司、把长老写成上司，道韵全无；
- **闭关跳时间**："十年后"用来跳过困难，等于抹掉冲突；
- **境界名词自创**：自创全套阶梯会显著提高读者理解成本，收益极低；
- **神通清单化**：一次性列出所有神通，后续无新鲜感。

### 5.7 映射

`long_arc.progression_ladders` 用公版阶梯；`story_state` 必须承载"当前寿元/时间流逝"，否则时间尺度必然漂移（当前 `state` 投影**未建模时间轴**，见 §12.2）。

## 6. 都市

流量极大、竞争极烈、生命周期最短的一类。

### 6.1 题材承诺

读者买的是**现实身份的即时逆转**：昨天被瞧不起，今天有钱/有能力/有背景。核心情绪是"现实代入 + 立刻打脸"。

弃书雷点：
- 装逼没有见证者（打脸必须有围观与传播）；
- 行业细节失真（金融、医疗、娱乐圈的常识错误立刻掉读）；
- 主角有钱却不花（读者要看消费与阶层跨越的具体画面）；
- 女性角色只作为战利品出现（评论区风险高）。

### 6.2 必备要素

| 轴 | 都市取值 |
|---|---|
| `mechanism` | 系统/异能/重生先知/专业技能/神豪资金；**收益必须现金化或身份化** |
| `ladder` | 财富 → 人脉 → 圈层 → 行业话语权 → 资本/规则制定者 |
| `map` | 校园或街区 → 公司 → 城市商圈 → 全国行业 → 国际/隐世 |
| `payoff_mix` | 关系爽 30%（打脸与认可）/ 能力爽 25% / 信息爽 20%（先知差）/ 结构爽 15% / 感官爽 10% |

都市题材的独特必备要素是**见证与传播**：任何爽点若无第三方看见并扩散，商业效力减半。这是都市与玄幻最大的技术差异。

### 6.3 开篇打法

- 第 1 章：**当场羞辱 + 立刻获得能力**是最高转化率的公版开局；
- 前 300 字必须出现具体的现实压力（欠款数额、退婚、失业、病历）；
- 第 2 章：能力换成第一笔可见收益（金额、职位、名声，须具体到数字）；
- 第 3 章：第一次公开打脸，并让"消息传出去"。

### 6.4 子类型

| 子类 | 差异点与风险 |
|---|---|
| 都市异能 | 最接近玄幻，需处理"力量与现实秩序"的关系（警察/军方为何不管） |
| 重生年代/金融流 | 靠先知差；需真实年代与行业考据，错一处即失信 |
| 娱乐圈文娱 | 靠作品展示（歌/剧/文），必须真的写出"好作品"的说服力；版权与真人指涉风险高 |
| 都市种田日常 | 慢节奏、低冲突，靠治愈与经营循环；付费转化偏弱 |
| 神豪流 | 强反馈短周期，极易疲劳，需持续升级消费层级 |
| 医武/医术流 | 专业密度要求高，误医学描写有现实风险 |
| 都市修真 | 与仙侠交叉，需解决"隐世设定"的一致性 |

### 6.5 节奏（经验区间）

- 单章 2000–2500 字（最短的一类，节奏最快）；
- 免费 15–30 章（比玄幻更早上架）；
- 大兑现每 10–20 章（最密）；小兑现每 2–3 章；
- 第一卷 50–80 章。

### 6.6 专属雷区

- **爽点通胀**：第 20 章就动用国家级资源，后期无处可升；
- **行业悬浮**：写投资不写风控、写医院不写流程；
- **打脸对象无学习**：反派反复送脸，读者疲劳最快；
- **合规**：真实公司/品牌/人物指涉、医疗与金融的可操作性描写、涉政涉军细节。

### 6.7 映射

都市对 `market_position.reader_segment` 的敏感度最高（同为都市，神豪与年代金融是两种读者）。`payoff_mix` 中"见证与传播"应写成 `chapter_objective.irreversible_change` 的一个明确取值类型。

## 7. 历史

写作门槛最高、读者最挑剔、也最容易触线的一类。

### 7.1 题材承诺

读者买的是**用现代认知改变已知结局**的智性满足，加上厚重的时代质感。核心情绪是"我知道后来会怎样，而我能改"。

弃书雷点：
- 考据失真（称谓、官制、物价、作物、器物、礼仪错误）；
- 现代人开局就横扫（古人被写成傻子）；
- 主角用现代知识无成本地造出工业品；
- 历史观轻浮（对战争、民族、屠杀的轻佻处理）。

### 7.2 必备要素

| 轴 | 历史取值 |
|---|---|
| `mechanism` | 现代知识差（技术/制度/军事/商业）+ 史料先知；**必须受材料、人力、政治现实约束** |
| `ladder` | 身份 → 官阶/爵位 → 实控地盘 → 军队 → 政权/王朝 |
| `map` | 一村一县 → 州郡 → 朝堂 → 边疆 → 天下 |
| `payoff_mix` | 信息爽 30% / 结构爽 25%（制度与势力改变）/ 关系爽 20% / 能力爽 15% / 感官爽 10% |

历史题材三个不可省要素：
1. **时代摩擦**：现代方案必须先撞上时代限制（没有钢、没有识字工匠、没有政治授权），再想办法；
2. **古人不傻**：对手用时代内的最优解博弈，且能识破主角的部分意图；
3. **代价具体**：改变历史必须付出人命、财政、信誉或权力的具体成本。

### 7.3 开篇打法

- 第 1 章：**穿越即危局**（战场、抄家、流放、饥荒），并在 300 字内落实时代坐标（年号、地点、身份）；
- 时代细节以"感官+具体物"给出（麻布刺喉、粟米粥、宵禁鼓声），不做说明文；
- 第 2 章：第一次动用知识差，但只解决小问题且暴露约束；
- 第 3 章：获得第一个身份/位置的实质提升（哪怕只是里正的信任），打开前十章目标。

### 7.4 子类型

| 子类 | 差异点与风险 |
|---|---|
| 架空历史 | 自造朝代，规避真人指涉风险，考据压力最低，推荐作为本项目起点 |
| 穿越争霸 | 军事+政权，需战争与后勤描写能力 |
| 宫廷权谋 | 靠信息爽与人物博弈，最考验群像与对话 |
| 历史种田基建 | 靠建设循环提供节奏，技术树需真实可行 |
| 军事历史 | 战术细节要求极高 |
| 历史同人（三国/大明/大唐/宋/秦） | 读者基数大但对既有人物性格容错极低；真实人物与民族议题风险最高 |

### 7.5 节奏（经验区间）

- 单章 2500–3500 字；
- 免费 30–50 章；
- 大兑现每 25–40 章（政权层级的兑现天然慢）；
- 第一卷 100–150 章。

### 7.6 专属雷区与合规

- **金手指过硬**：随手炼钢、造枪、开银行，抹掉一切时代摩擦；
- **称谓与官制错误**：这是历史读者的第一试金石；
- **历史观风险（重点）**：民族关系、战争暴行、真实历史人物的评价、涉及国家主权与领土的表述，须严格审慎；不做美化侵略、不轻佻处理民族苦难；
- **真实人物**：直接指涉近现代真实人物风险显著高于古代人物；
- 结论：**本项目若要生成历史题材，默认应走"架空历史"**，把真人真事指涉作为需要人工审批的高风险路径。

### 7.7 映射

历史题材需要一类当前不存在的检查：**时代一致性检查**（anachronism check）。现有 `text_integrity`/`redline` 只做确定性字符级与红线检查，无法发现"唐代出现玉米"。这是 §12.3 提出的新检测器候选。

## 8. 游戏

结构最规整、最适合系统化生产的一类——因为游戏题材自带节奏器（等级、副本、赛程）。

### 8.1 题材承诺

读者买的是**清晰规则下的最优解快感**：数值成长、机制利用、团队协作、竞技胜负。核心情绪是"我看懂了规则并玩赢了"。

弃书雷点：
- 机制不自洽（数值/技能前后矛盾，读者会算）；
- 主角赢在数值不赢在操作与理解；
- 副本描写变成打怪流水账；
- 现实线与游戏线互不影响（游戏输赢没有现实重量）。

### 8.2 必备要素

| 轴 | 游戏取值 |
|---|---|
| `mechanism` | 面板/职业/技能树/装备/副本规则；**必须可验算、前后一致** |
| `ladder` | 等级 → 装备/职业 → 公会/队伍 → 服务器/赛区 → 版本话语权 |
| `map` | 新手村 → 主城 → 野外区域 → 团本 → 跨服/赛事 |
| `payoff_mix` | 能力爽 30% / 信息爽 25%（攻略差）/ 关系爽 20%（队伍与公会）/ 结构爽 15% / 感官爽 10% |

游戏题材的独特必备要素是**规则可验算性**：读者会拿计算器算你的伤害公式。数值一旦自相矛盾，信任崩塌速度快于任何其他题材。因此：
- 数值体系必须在 Brain 中写成**表**，不是散落在正文；
- 技能一旦定义，效果与代价不可随剧情更改；
- 主角的胜利须能被读者复现推导。

### 8.3 开篇打法

- 第 1 章：**现实困境 + 进入游戏**，且现实困境要具体到金额或期限（为什么必须靠游戏翻身）；
- 前三章必须完成一次"用机制理解取胜"的示范（不是等级压制）；
- 第 2 章：拿到第一个机制优势（隐藏职业/前世攻略/BUG 利用），并说明其边界；
- 第 3 章：小规模团队战或 PVP 胜利，让"操作+理解"成为作品承诺。

### 8.4 子类型

| 子类 | 差异点与风险 |
|---|---|
| 网游虚拟现实 | 经典形态，现实线与游戏线双轨，须互相影响 |
| 游戏系统降临现实 | 与都市/末世交叉，规则冲击社会秩序，结构爽空间最大 |
| 电子竞技 | 靠赛程节奏与队伍群像；真实赛事、真实选手、真实游戏指涉有版权与名誉风险 |
| 游戏制作人流 | 主角做游戏，卖点是"设计思路"，需真的写出好设计 |
| 无限副本 | 实为无限流，见 §10 |

### 8.5 节奏（经验区间）

- 单章 2000–3000 字；
- 免费 20–35 章；
- 大兑现每 15–25 章（副本/赛事天然分段）；
- 第一卷 60–100 章。

### 8.6 专属雷区

- **数值漂移**：这是游戏题材的第一死因；
- **副本同构**：每个副本都是"进入—打—通关"，缺少规则差异；
- **公会政治缺席**：团队题材没有人事冲突，群像空洞；
- **版权指涉**：真实游戏名、真实公司、真实赛事与选手，建议全部虚构化。

### 8.7 映射

游戏题材对本项目最友好：`chapter_objective` 的 `payoff_target` 可直接绑定副本/等级里程碑；但需要一个**数值一致性检查**（同一技能在不同章的数值是否冲突）——现有 `state` 投影只 fold facts，不校验数值单调性，见 §12.3。

## 9. 科幻

起点男频中读者规模偏小但忠诚度高、天花板高的一类。

### 9.1 题材承诺

读者买的是**新奇设定带来的认知冲击 + 人类处境的宏大感**。核心情绪是"原来还能这样"。

弃书雷点：
- 设定自嗨（几千字讲曲率引擎，主角没有动作）；
- 点子写完就没了（一个创意撑不过 30 章）；
- 硬度失衡：术语密集但故事空转；
- 星际战争没有战术，只有舰队数量。

### 9.2 必备要素

| 轴 | 科幻取值 |
|---|---|
| `mechanism` | 科技/进化/异能/AI/时间机制；**须有明确的物理或规则边界**，且边界可被利用 |
| `ladder` | 个人装备/改造 → 舰船 → 舰队/基地 → 星系 → 文明层级（卡尔达舍夫式分级最易懂） |
| `map` | 单点（舰/站/城）→ 行星 → 星系 → 星区 → 宇宙尺度真相 |
| `payoff_mix` | 信息爽 30%（认知反转）/ 结构爽 25% / 能力爽 20% / 感官爽 15% / 关系爽 10% |

科幻三个不可省要素：
1. **一个核心点子（Big Idea）**，且这个点子能持续产生新问题，不是一次性奇观；
2. **可利用的规则边界**：读者要能预判"主角会怎样用这条规则"；
3. **人的处境**：技术冲击必须落到具体人的选择上，否则沦为设定集。

### 9.3 开篇打法

- 第 1 章：**异常现象 + 生存压力**（警报、变异、倒计时），不做设定介绍；
- 设定通过"操作"给出（主角检修、诊断、驾驶），而不是通过解说；
- 第 2 章：核心机制首次生效，同时给出物理代价（能耗、辐射、寿命、算力）；
- 第 3 章：用规则理解解决危机，确立"这本书靠脑子"的承诺。

### 9.4 子类型

| 子类 | 差异点 |
|---|---|
| 星际战争 | 需战术与后勤，群像与指挥线 |
| 末世废土 | 与都市/游戏交叉，靠资源匮乏提供密集冲突，最易上手 |
| 赛博朋克 | 阶级与义体，调性偏黑暗，需希望锚点 |
| 硬科幻设定流 | 门槛最高，读者最少但最忠诚 |
| 时间循环 | 天然的重复结构，须每轮有信息增量（与无限流共享结构风险） |
| 超能力进化 | 最接近玄幻的科幻皮肤，商业转化最稳 |
| 科幻基建 | 建设循环提供节奏，技术树需自洽 |

### 9.5 节奏（经验区间）

- 单章 2500–3500 字；
- 免费 25–45 章；
- 大兑现每 25–35 章；
- 第一卷 80–120 章。

### 9.6 专属雷区

- **设定倾泻**：开篇技术名词过载，是科幻第一弃书原因；
- **点子透支**：核心创意在前 20 章用尽；
- **尺度失控**：过早进入宇宙尺度，个人行为失去意义；
- **人物工具化**：科幻最容易写出"没有人只有设定"的稿子。

### 9.7 映射

科幻的 `forbidden_style` 必须写入「技术名词倾泻」「无动作解说段」。density 检测器的 dialogue floor（`density.py:58`，5%）对科幻尤其有用——设定解说段落天然对白稀少，这正是需要预警的信号。

## 10. 诸天无限

结构最特殊的一类：它不是"一个世界的长篇"，而是"多个短篇的连载"。所有通用长篇规范在此需要额外一层结构约束。

### 10.1 题材承诺

读者买的是**熟悉世界的重逢 + 跨世界的收集与成长**。核心情绪是"带着外挂回到我熟悉的故事里"，以及"我的积累在变多"。

弃书雷点：
- 逛世界没有主线（每个副本互不相干，读者随时可以停）；
- 副本同构（进入—适应—通关—离开，每次都一样）；
- 强弱失衡：主角在原著世界里无敌，冲突消失；或反之被吊打得毫无爽感；
- 原著角色 OOC（读者因为熟悉才来，人物走形是最大背叛）。

### 10.2 必备要素

| 轴 | 诸天无限取值 |
|---|---|
| `mechanism` | 主神/系统/轮回空间；**必须有跨世界继承规则**（什么带得走、什么带不走、代价是什么） |
| `ladder` | 个人属性 → 技能/血脉收集 → 团队 → 空间权限 → 主神/规则层真相 |
| `map` | 单副本 → 多副本串联 → 空间内部势力 → 主神层 → 多元宇宙真相 |
| `payoff_mix` | 信息爽 30%（先知原著）/ 能力爽 25% / 结构爽 20% / 关系爽 15% / 感官爽 10% |

诸天无限有**三条其他题材没有的结构必备要素**：

1. **跨副本累积轴**：必须存在一条只增不减、读者可数的积累（技能数、血脉、空间点数、队友），否则每个副本结束时读者的投资归零；
2. **跨副本主线**：主神的目的、回家的路、幕后敌人——必须在每 2–3 个副本推进一次，否则作品没有终点感；
3. **副本差异化契约**：相邻副本必须在**规则类型**上不同（生存型/解谜型/阵营型/养成型/竞速型），不只是换背景。

### 10.3 开篇打法

- 第 1 章：**被拉入空间 + 立刻面临死亡规则**，规则条文要具体（几小时、什么条件、失败即死）；
- 第一个副本必须选**读者认知成本最低**的世界，并在 3 章内完成一次规则利用；
- 第 2 章：拿到第一件可继承的东西，明确"这个能带走"；
- 第 3 章：第一次靠原著先知 + 空间能力赢，确立双重优势的承诺。

### 10.4 子类型

| 子类 | 差异点与风险 |
|---|---|
| 主神空间无限流 | 经典形态，靠死亡压力与团队博弈；需处理"队友死亡"的情绪管理 |
| 诸天万界（影视动漫世界） | 拉新最快但**版权风险最高**：直接使用他人作品的世界与角色 |
| 签到流 | 低冲突、强反馈、疲劳最快，需持续升级签到收益层级 |
| 多元宇宙收集流 | 强调积累，须防"清单式写作"（收集变成报表） |

### 10.5 版权与合规（本节为硬约束）

诸天无限是九题材中**唯一在结构上就依赖他人 IP** 的类别。对本项目而言：

- 直接使用现存影视/动漫/游戏作品的世界观与角色，属于对第三方著作权的使用，**不是原创**；
- 本项目已有 M7 原创性/相似度检测（`runtime/execution/m7.py`），但它检测的是**文本相似**，检测不到"设定与角色的整体挪用"；
- 因此规则是：**诸天无限题材默认只允许"自造世界群"**（原创的多个世界/文明），把"穿越到现存作品"列为需要人工授权与法律判断的高风险路径，由 ADR-009 的人类权威边界处理，系统不得自动生成；
- 相应地，`market_position` 中若出现"诸天/万界+已知 IP 名"，应触发 `hold` 而非 `admit`。

### 10.6 节奏（经验区间）

- 单章 2500–3500 字；
- 单副本 15–40 章（低于 15 章世界立不住，高于 40 章读者疲劳）；
- 免费 25–40 章（约等于第一个副本走完）；
- 主线推进每 2–3 副本一次；
- 大兑现在每个副本结束时（天然分段）。

### 10.7 专属雷区

- **副本同构**：最主要死因，须用"规则类型轮换"对抗；
- **积累不可感**：读者说不出主角现在有几个技能；
- **原著角色沦为背景**：只借名字不借性格，失去题材承诺；
- **无限流的憋屈过载**：死亡压力过强而无阶段胜利，读者情绪断裂。

### 10.8 映射

诸天无限暴露了本项目结构层的一个真实空白：现有 `long_arc` 建模的是**单一连续世界**的境界/地图曲线，而无限流需要"**副本容器 + 跨副本继承**"两层模型。`chapter_bands` 可以承载副本分段，但"什么能带走"这条继承规则当前无处安放（见 §12.4）。

## 12. 对本项目的缺口分析（基于代码事实）

以下每条均给出可验证的代码位置。这部分回答"文档要怎么帮项目变完善"。

### 12.1 题材白名单缺六个题材（P0，确定性缺陷）

`runtime/positioning/generate.py:32` 与 `runtime/genesis/brain_gen.py:25`：

```python
_MALE_LEAN = {"玄幻", "仙侠", "科幻", "奇幻"}
```

`channel = mp.get("channel") or ("男频" if primary_genre in _MALE_LEAN else "女频")`

后果：**武侠、都市、历史、游戏、诸天无限五个男频题材在 market_position 沉默时会被静默判为女频**，进而污染 `reader_segment`、`leans_on` 与 admission 判断。这不是评价性偏差，是确定性错误。

同样的问题在 `runtime/market/analyzer.py:16` 的 `MALE_GENRES`：只有无限流/幕后流/领主流/修仙/克苏鲁/都市异能/科幻七个关键词组，**没有武侠、历史、游戏、玄幻**（"玄幻"本身不在表内，只有"修仙"）。题材热度信号因此对四个大类完全失明。

修法（additive，不碰 frozen schema）：把题材表提到一处配置，覆盖九题材及其子类关键词，两处 `_MALE_LEAN` 引用同一常量（注释里已经写了"kept in sync"，说明作者知道重复的风险）。

### 12.2 时间/寿元轴缺失（仙侠、历史受影响）

`StoryState` 是 `fold(facts, events)` 的投影，建模了实体与关系，但**没有时间轴**。仙侠的"闭关十年"、历史的"三年后北伐"无法被状态承载，因此模型每章都可能重新编造时间流逝量。表现为：时间尺度漂移，读者立刻发现矛盾。

修法：在 `state` 投影里加一个只读的 `timeline` 维度（fold 事件的时间标注），advisory 呈现给 prompt。属于 ADR-008 允许的新投影，不引入可变状态。

### 12.3 缺两类题材专属检测器

现有检测器族（`density.py:58` `DIALOGUE_FLOOR=0.05`、`humanization.py:43` `ANAPHORA_RUN_MAX=3`、`humanization.py:45` `SENTENCE_CV_FLOOR=0.35`、pacing、end_hook、openings）全部是**文体层**的，且阈值全局固定、与题材无关。缺两类**题材语义层**检测器：

1. **时代一致性检查（历史/武侠/仙侠）**：检测年代错置物（唐代玉米、宋代辣椒、明代怀表）。可做成确定性词表检查——给定 `brain.setting.era`，比对禁用物名单。这类检查有确定性依据，但仍应 `gating=false`（词表必然不全，误报会阻断好章）。
2. **数值一致性检查（游戏/玄幻/科幻）**：同一技能/境界/装备的数值在跨章出现时是否冲突。这是 fold 型检查，与 `long_novel_memory` 的因果 GATE 同族。

阈值题材化也是一个具体机会：科幻/历史的解说段天然对白稀少，`DIALOGUE_FLOOR=0.05` 对它们是合理预警；但都市对白密度天然高，同一个 floor 几乎永不触发，等于对都市失效。**阈值应按题材取不同值，而不是全局一个数**。

### 12.4 无限流的"副本容器 + 继承"两层模型无处安放

`long_arc.progression_ladders` / `chapter_bands` 建模的是单一连续世界的单调曲线。诸天无限需要：
- 副本容器（每个副本是一个有独立规则类型的子结构）；
- 跨副本继承规则（什么带得走）；
- 副本规则类型轮换约束（相邻副本不同型）。

这是九题材里唯一需要**结构层扩展**而不只是参数化的题材。建议：本项目**先不做诸天无限**，把它列为 Phase N 的显式扩展项，而不是假装现有 long-arc 能覆盖。

### 12.5 参考锚（reference band）未按题材分组

`runtime/reference/profile.py:80` `build_reference_profile(sources, ...)` 对传入的所有 sources 统一算 band，无题材分组。后果：若参考小说混入不同题材，band 会被拉平——用都市的对白密度去要求科幻，或反之。

修法：profile 按 `genre` 分桶，gap 检查取**同题材**的 band。这直接提升现有市场锚定 hygiene 回路（已在 `prose_hygiene` 中 live）的精度。

### 12.6 prompt 层无题材分支

13 个模板（`AI-Novel-Standard/contracts/prompts/chapter-draft.v1..v13.prompt.yaml`）中没有任何题材条件分支。题材信息目前只能通过 `style` / `context_lines` / `story_state` 的自由文本间接进入。

考虑到 §11.3 的"向玄幻漂移"偏置，建议增加一个 `genre_contract` prompt 变量（承诺 + 判别式要素 + 禁写清单），按现有 optional-variable 惯例绑定（`runtime/prompt/binding.py`）：只在提供时绑定，旧版本渲染保持逐字节一致。这是本项目已经验证过多次的非破坏性扩展方式。
