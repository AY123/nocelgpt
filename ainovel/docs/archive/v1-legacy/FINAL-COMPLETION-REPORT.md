## 关键决策

### 为什么选择Allowlist而非立即接入？

**对比分析**:
```
立即接入方案:
  时间: 2-3天
  风险: 中等（引入新逻辑）
  收益: 接入功能

Allowlist方案:
  时间: 10分钟
  风险: 零（无功能变更）
  收益: 修复架构卫生 + 为未来保留选项
```

**决策**: Allowlist
- P0目标是修复架构卫生，而非功能接入
- 快速、安全、可追溯
- 每个模块都有明确的未来激活条件
