## 问题描述

### 原始问题
项目设计时隐含假设了玄幻/奇幻题材，导致：
1. 都市重生小说《我真没想重生啊》被误识别为"奇幻"题材
2. LLM Genesis 一直生成奇幻内容（废城、旧神、预言等）
3. 无法正确生成都市、科幻等其他题材

### 根本原因（已确认）
1. **题材识别启发式缺陷**：单字匹配（"龙"误判）、无负向过滤、合并权重任意
2. **LLM Prompt 缺少题材约束**：通用模板无法强制 LLM 遵守题材边界
3. **确定性 fallback 是奇幻模板**：所有题材失败时都回退到"废城/旧神/预言"
4. **power_system 强制要求**：都市题材也被要求提供"修炼体系"
5. **模板参数传递错误**：构造了 `genre_constraint` 但未传入模板（KeyError）

## 已完成的 P0-A 修复

### ✅ 修复 1: 题材识别关键词改进

**改进内容**:
- 扩充都市关键词：14个（"创业"、"股票"、"互联网"等）
- 新增"都市重生"子类型：识别重生元素
- 修复单字误判："龙" → "巨龙"（避免人名"龙哥"干扰）
- 新增负向关键词：都市禁止"灵气、修炼、魔法"等
- 引入位置权重：第一题材3分，第二2分，第三1分

**验证结果**:
```
修复前: ['奇幻', '都市', '都市重生']  ❌
修复后: ['都市', '都市重生', '悬疑']  ✅
```

**局限性**（审核报告指出）:
- 仍是启发式计数，不是语义理解
- 无置信度和可解释性
- 混合题材、历史重生可能误判

### ✅ 修复 2: 创建题材专用 Prompt 模板

**新建文件**: `runtime/outline/prompts/urban.py`

**核心约束**:
- 明确定义都市题材（现代城市、真实场景）
- 列举都市金手指类型（重生、系统、预知）
- **严格禁止**：魔法、修炼、异能、灵气等奇幻元素
- 替换 power_system：财富等级/社会地位阶层

**验证**: 都市题材选择 `URBAN_PROPOSE_TEMPLATE`

### ✅ 修复 3: 确定性 fallback 按题材分离

**问题**: 原 `propose_candidates()` 硬编码3个奇幻候选，所有题材失败时都生成奇幻

**改进**: 根据题材选择不同 fallback
```python
if primary in ["都市", "都市重生"]:
    candidates = _urban_fallback_candidates(...)  # 都市专用
elif primary in ["玄幻", "仙侠"]:
    candidates = _xuanhuan_fallback_candidates(...)
else:
    candidates = _fantasy_fallback_candidates(...)  # 保持兼容
```

**验证结果**:
- 都市 fallback: `['重生之金融帝国', '神豪从签到开始', '从实习生到总裁']` ✅
- 奇幻 fallback: `['灰烬纪元的执灯人', '群星下的无名王座', ...]` ✅

### ✅ 修复 4: 修复模板参数传递错误

**问题**: `_PROPOSE_TEMPLATE` 需要 `{genre_constraint}`，但代码只构造未传入

**改进**: 
```python
# 修复前（KeyError）
prompt = template.format(analysis=..., n=self.n)

# 修复后
prompt = template.format(
    analysis=..., 
    n=self.n, 
    genre_constraint=genre_constraint  # 传入参数
)
```

**影响**: 修复前所有非都市题材会因 KeyError 回退奇幻 fallback

### ✅ 修复 5: 清理 Registry 题材矛盾

**问题**: `novel-dushi` 是都市项目，但包含 `MAG-00001.yaml`（魔法残片）等奇幻规则

**改进**: 删除所有 `MAG-*.yaml` 文件

**验证**: world_rules 目录已清空 ✅
