### 债务2：依赖完整性问题

**Import Plan 依赖**:
- 30个章节事件（EVT-90004~90033）
- 1个 Timeline（TML-90001）
- 1个 Character（CHR-90001）
- 3个 WorldRule
- **3个卷级事件**（EVT-90001~90003）

**问题**:
1. **不能只导入章节事件**
   - 章节事件引用 TML-90001
   - 引用 CHR-90001
   - 需要一起导入

2. **卷级事件的因果链**
   - EVT-90004.causes = [EVT-90003]（卷级）
   - 如果移除卷级事件，causes 悬空
   - 必须重写为 causes = []

3. **完整依赖图**:
   ```
   TML-90001
     ├─ EVT-90001 (卷级-起势)
     ├─ EVT-90002 (卷级-破局)  
     ├─ EVT-90003 (卷级-问鼎)
     ├─ EVT-90004 (第1章) → causes: [EVT-90003] ⚠️
     ├─ EVT-90005 (第2章) → causes: [EVT-90004]
     └─ ...
   
   CHR-90001 (主角)
     └─ 被所有章节事件引用
   ```

**正确处理**:
```python
# 1. 导入 TML-90001
# 2. 导入 CHR-90001
# 3. 导入 WorldRule
# 4. 处理卷级事件：
#    - 方案A: 标记为 arc_metadata，不参与 Serial
#    - 方案B: 完全移除，修复 EVT-90004.causes = []
# 5. 导入 30个章节事件
# 6. 验证引用完整性
```
