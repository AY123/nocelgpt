# AINovel

ANovel / ANES 的项目索引与事实入口。

本仓库当前的推进重点不是继续扩建工程结构，而是把“能生成内容”收口为“能稳定产出可审计、可复盘、可校准的中文商业网文正文”。

## 当前状态

- 工程骨架与事实治理能力已成形。
- 根层历史模板 README 已被替换为项目事实入口。
- 当前重点已转到正文质量与事实回流：30 章真实基线、人工金样集、自动修订净收益验证、100 章长线规划、事实回流链路。
- 近期已完成/落盘：金样集 50 条、Reviewer 校准骨架、W10 盲评批次骨架、W11 100 章长弧计划、W12 事实回流计划与 synthetic 测试链路。

## 权威文档

优先阅读以下文档：

1. `docs/ANOVEL_FUTURE_PLAN.md`：后续 12 个月实施路线图
2. `docs/ANOVEL_EXECUTION_TASKS.md`：阶段任务拆解
3. `docs/ANOVEL_WEEKLY_EXECUTION_PLAN.md`：周推进计划
4. `ROADMAP.md`：已完成与延期的 as-built 账本

## 项目边界

- `ROADMAP.md` 只记录已完成与延期，不承担前向规划职责。
- `docs/ANOVEL_FUTURE_PLAN.md` 只描述未来路线，不重复已完成事实。
- `docs/ANOVEL_EXECUTION_TASKS.md` 只承接阶段任务，不替代周计划。
- `docs/ANOVEL_WEEKLY_EXECUTION_PLAN.md` 只用于每周推进，不承载长期战略。
- 若与仓库事实冲突，以仓库事实为准。

## 当前推进原则

- 先做事实恢复，再做正文质量，再做 30 章基线，再做金样集校准，再做自动修订验证，再做百章生产。
- 不以新增 Agent、Schema 或报表数量代替小说质量与商业验证。
- 未校准信号只能用于诊断，不能直接驱动强决策。
- 所有事实写入必须通过唯一 Mint 入口，不允许旁路。
- 所有发布、上架与商业判断，必须保留人类授权。
