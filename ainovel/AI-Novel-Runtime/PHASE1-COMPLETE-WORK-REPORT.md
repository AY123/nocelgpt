## 🎯 技术亮点

### 1. 量化定位指令

**Before** (RUN-00001):
```
"连续3句同头排比，建议打散句式"
→ 模型需要自己找，容易遗漏
```

**After** (Phase 1):
```
"第5-7句（约第500-800字）出现同头排比（他...），
「他知道这是危险的」；「他知道必须小心」；「他知道没有退路」，
请改写至少2句的开头"
→ 精确引用，无法遗漏
```

---

### 2. 高频模板检测

**检测到的17个模板**:
```python
{
  "他知道": 0.5,      # 基准每千字0.5次
  "这不是": 0.3,
  "沉默了片刻": 0.1,
  "深吸一口气": 0.2,
  "眼中闪过": 0.3,
  "嘴角勾起": 0.2,
  "如同": 0.5,
  "仿佛": 0.4,
  ...
}
```

**建议替代**:
- "他知道" → ["他明白", "他清楚", "他意识到", "他发现"]
- "沉默了片刻" → ["静默良久", "短暂的沉默", "陷入沉默"]

---

### 3. 多轮收紧策略

```
┌─────────────────────────────────────────┐
│ Attempt 1: target=3333, ceiling=3999    │
│ (tolerance=0.2, 给模型正常发挥空间)      │
└─────────────────────────────────────────┘
         ↓ 如果超长 (4500字)
┌─────────────────────────────────────────┐
│ Attempt 2: target=3333, ceiling=3666    │
│ (tolerance=0.1, 明确指令收紧)           │
│ "上一版超长4500字，本次必须控制在3666" │
└─────────────────────────────────────────┘
         ↓ 如果仍超长
┌─────────────────────────────────────────┐
│ Attempt 3: 硬截断                        │
│ 在完整句处截断到target±tolerance         │
└─────────────────────────────────────────┘
```
