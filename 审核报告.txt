二、Resume/Handoff 实现质量不错

我专门检查了 task_entry.py。

当前 observe() 会实际记录：

repository root
branch
HEAD
dirty
git status hash
index hash
tracked file bytes/hash
untracked file bytes/hash
symlink identity
Python version

Resume 时要求：

previous.status == PASS
previous.task_id == current task
previous.action == current action
previous.after == current before

否则拒绝。

也就是说这种情况：

上一个 AI：
“我已经做到第 7 步”

但实际：

HEAD changed
或者文件 changed
或者 untracked changed

不会直接继承成功。

这个设计是对的。

三、FAIL / UNKNOWN 处理也是正确的

例如：

child exit 7
→ FAIL

不会被包装成：

entry command ran successfully
→ PASS

超时：

timeout
→ UNKNOWN

后续：

UNKNOWN
→ 不能 resume 成 PASS

甚至测试了：

child command 本身 exit=0
但命令破坏了 .git/HEAD
导致 post-command observation 无法完成

最终结果仍然：

UNKNOWN

而不是：

command exit 0
→ success

这一点非常好。
