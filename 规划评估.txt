ANovelOS V2 项目全面深度评估报告二

  我已经按当前 main@b835d698 重新做了一轮深度审核。和上一版相比，这次更新有实质进步，尤其是外部优秀项目经验已经正式进入机器控制面；但新加入的独立深度审计也确实挖出了此前验证器的几个真实缺口。

十、DA-04 — Task Readiness / Entry Gate / ADR 仍然可以被部分绕过

当前 validator 有：

    check(previous_phase_verified)

这个逻辑有一个明显缺口：

所以：

理论上 P0 Task 仍可能进入：

IN_PROGRESS

同时：

是单向检查。

如果把 Task 中：

  - ADR-001

删掉，

ADR-001

仍然认为自己属于 V2-001，

Task.required_decisions

必须完全一致。

类似：

Task.related_findings

Finding.related_tasks

并且 Task 开始必须检查：

task.readiness
start_gate
dependencies
due ADRs
phase gate

而不是只检查其中几个。
