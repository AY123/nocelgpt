## 恢复与后续

重复/迁移文件按 JSON 的 `retained_path` 查找。旧根 ZIP 可用 Git 导出：`git show <recovery_git_revision>:<recovery_git_path> > <目标文件>`，字段取自该条记录；恢复后核对 SHA-256。不要用整个工作区 reset 来恢复一个文件，避免覆盖尚未提交的规划改动。
